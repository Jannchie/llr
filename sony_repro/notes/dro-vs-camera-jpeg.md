## 0. 结论

1. **llr 的 DRO 对 Edit 同档位已经对上了,自动档和手动档都是。** 两帧、五个档位,整幅 ΔL\* 在 −1.6 ~ +0.4,
   除极暗(Y<0.05,占 0.5~6%)和纯白外各亮度段 ≤1.5 L\*;16 px 低频差中位 ≤1.0/255。DRO 关时也是这个量级
   (0.6/255),所以剩下的不是 DRO 的。
2. **用户感到的「差别大」是拿机内 JPEG 当参照。机内 JPEG 和 Edit 自己就差 +2 ~ +3 L\*,而且差的是一条全局曲线**:
   把「机内 − Edit 自动」按 Edit 的 Y 分 64 桶扣掉中位曲线后,32 px 低频残差从 5.4 掉到 0.8/255 ——
   **机内的局部处理(DRO 的空间项)和 Edit 一样,不一样的是全局影调**。llr 复刻的是 Edit,所以对机内也差这一条。
3. **手动档:Edit 的 DRO「手动」是一根 0..100 的滑块,滑块值 = 引擎 level**(0 → P0,50 → P5,逐段对上);
   llr 的 Lv1..5 = 10/30/50/70/90 是我们对同一刻度的五点量化,不是相机菜单里的 Lv1..5。
   相机 Lv1..5 对应引擎哪个 level 语料里没有(只有 Auto 帧),对不上是意料之中。
4. 网格不是可选项:DSC02948 上全局回退比 Edit 暗 4 L\*(中间调 Y 比 0.90~0.93),网格路径 +0.33 L\*。

## 4. 如果要「像机内」而不是「像 Edit」

DRO 不用动。要补的是一条**全局**曲线(暗部再抬、中间调回压、高光压 5%),两帧的形状一致,
可以从「机内 / Edit 自动」的按 Y 中位曲线直接拟合;但那是另一个目标(机内 JPEG 的色调链),不属于 DRO 复刻。
