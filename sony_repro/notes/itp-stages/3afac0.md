# 0x3afac0 —— 垂直同色二阶差分 + 绿点掩码取绝对值（3af8d0 的垂直孪生）

指令 147 条。

## 1. 签名

栈帧：`mov [rsp+8], rbx` → 7 个 push → `sub rsp,0xb0`，入口 rsp = R，当前 rsp = R-0xe8。
`mov rax,[rsp+0x110]` = [R+0x28] = 第 5 参数。

| 参数 | 寄存器 | 用法 | 读到的字段 |
|---|---|---|---|
| p1 | rcx | **未使用** | — |
| p2 | rdx → rsi | float 平面描述符，**输出**：带符号二阶差分；同时**整个循环的尺寸都取自它** | +0 宽、+4 高、+8 行距、+0xc 字节大小(memset)、+0x10 数据 |
| p3 | r8 → r15 | float 平面描述符，**输出**：\|二阶差分\| × 相位掩码 | +4 高、+8 行距、+0x10 数据 |
| p4 | r9 → r14 | float 平面描述符，**输入**源平面 | +4 高、+8 行距、+0x10 数据 |
| p5 | [R+0x28] | 指针，仅在返回前写 `*p5 = &vftable(0x466678)`（与 3af8d0 的 ROI 对象同类型，但本函数**没有读它的任何字段**） | — |

开头 `memset(p2.data, 0, p2[+0xc])`。

## 2. 循环结构

- 外层：`ecx = 2`，`while (ecx < p2.height - 2)`，每次 +1。**行方向留 2 像素余量**（垂直滤波需要）。
- 内层：完全**不**用 ROI，从列 0 开始覆盖整幅宽度：迭代次数 `((width-1)>>3)+1`，即 `ceil(width/8)`，每次 8 个 float。**列方向没有余量**。
- 无标量尾循环，尾部靠向上取整的向量数覆盖（会越写不超过 7 个 float）。
- 与 3af8d0 的边界互补：那个留列余量不留行余量，这个留行余量不留列余量。

行指针：p4 取三行 `y-2 / y / y+2`（r10 / r11 / r8），p2 取 `y`（rdx），p3 取 `y`（r9）。之后把 r11、r8、r9、r10 全部减掉 rdx 变成差量寻址。

## 3. 抽头几何

只读 p4，同一列：

| 输入 | 行偏移 | 列偏移 | 位移 |
|---|---|---|---|
| p4 | -2 | 0 | 行距×(-2) |
| p4 | 0 | 0 | 0 |
| p4 | +2 | 0 | 行距×(+2) |

## 4. 常量

| RVA | 值 | 载入方式 | 角色 |
|---|---|---|---|
| 0x4DEBBC | **1.0f** | `vbroadcastss ymm2` (3afb1b) | 相位掩码的「选中」值 |
| 0x4DEAE4 | **0.25f** | `vbroadcastss ymm3` (3afb61) | 二阶差分归一化 |
| 0x469800 | **-0.0f** | `vbroadcastss ymm4` (3afb6a) | `vandnps` 取绝对值 |
| 0x559440 | — | `[rip+0x1a9959]` | __security_cookie |

死存储交叉验证：`[rbp+0x60]` 依次被写入 `0x3f800000`(1.0)、`0`、`0x3e800000`(0.25)、`0x80000000`(-0.0)。

掩码构造与 3af8d0 完全一致：`maskA=[1,0,1,0…]` 存 [rbp+0x20]，`maskB=[0,1,0,1…]` 存 [rbp+0x40]，每行按 `y&1` 选。这里 lane0 就是绝对列 0，所以掩码就是「偶行取奇列、奇行取偶列」= RGGB 下的**绿色位置**。

## 5. 算式

```
memset(p2, 0)
for y in [2, H-2):
    m = (y & 1) ? [1,0,1,0,...] : [0,1,0,1,...]
    for x in 0..W step 8:
        L = 0.25 * (2*p4[y][x] - p4[y-2][x] - p4[y+2][x])
        p2[y][x] = L
        p3[y][x] = |L| * m[x]
```

## 6. 调用

| 目标 RVA | 形式 | 说明 |
|---|---|---|
| 0x3a8a2d | 直接 call | memset |
| 0x3a5630 | 直接 call | __security_check_cookie |

## 7. 一句话定性

**垂直方向的同色二阶差分 + 绿点方向代价**，与 0x3af8d0 逐条对偶（唯一差别：行/列余量对调、尺寸取自 p2 而非 ROI）。
