# 0x3b14a0 — 5×5 棋盘格加权核 + CFA 相位归一化（223 条指令）

## 1. 签名
`void f(p1 /*未用*/, PlaneF32* pDst, PlaneF32* pSrc, Roi* pRoi)` —— 4 个参数。

| 参数 | 寄存器 | 类型 | 用法 |
|---|---|---|---|
| 1 | rcx | ? | 入口就被 `mov [rax+8], rbx` 把 home slot 当溢出位覆盖掉，全函数未读 → `this` |
| 2 | rdx→`[rbp]` | float32 平面描述符 | `+4`(高) `+8`(行距) `+0x10`(数据)。**写入目标**（只用行 y） |
| 3 | r8→`[rbp+8]` | float32 平面描述符 | `+4` `+8` `+0x10`。**读取源**（用 5 行：y−2..y+2） |
| 4 | r9→r12 | ROI/任务对象 | `+8`=x0, `+0xc`=y0, `+0x10`=x1, `+0x14`=y1；退出前 `+0` 写 vftable |

## 2. 循环结构
- 外层：`ecx = y`，从 `Roi.y0 + 2` 到 `Roi.y1 - 2`（`y1` 每轮重载），步进 1；`r13d = y+2` 同步递增。
- 内层：`r8d = x`（存于 `[rbp+0x40]`），从 `Roi.x0 + 2` 到 `Roi.x1 - 2`，**步进 8**。
- do-while，**无标量尾**，最多多写 7 像素。
- 每轮外循环用 `test cl,1` 按**行奇偶**在两个 32 字节常量向量之间做 `cmove`，选出本行的归一化系数 `ymm6`。

## 3. 抽头几何
基址（首轮 x = x0+2，之后每轮 +0x20）：
- `rdi = pSrc.row(y-2) + 4*(x-1)`
- `rbx = pSrc.row(y-1) + 4*(x+2)`
- `r10 = row(y) − row(y-2)`，`r9 = row(y+1) − row(y-2)`，`rdx = row(y+2) − row(y-2)`（差值寻址）
- `rsi = pSrc.row(y+2) + 4*x`
- `r11 = pDst.row(y) − pSrc.row(y-2)`

完整 5×5 邻域（25 抽头，一个不落）：

| 行偏移 \ 列偏移 | −2 | −1 | 0 | +1 | +2 |
|---|---|---|---|---|---|
| **−2** | `[rdi-4]` | `[rdi]` | `[rdi+4]` | `[rdi+8]` | `[rdi+0xc]` |
| **−1** | `[rbx-0x10]` | `[rbx-0xc]` | `[rbx-8]` | `[rbx-4]` | `[rbx]` |
| **0** | `[r10+rdi-4]` | `[r10+rdi]` | `[r10+rdi+4]` | `[r10+rdi+8]` | `[r10+rdi+0xc]` |
| **+1** | `[r9+rdi-4]` | `[r9+rdi]` | `[r9+rdi+4]` | `[r9+rdi+8]` | `[r9+rdi+0xc]` |
| **+2** | `[rdx+rdi-4]` | `[rdx+rdi]` | `[rsi]` | `[rdi+rdx+8]` | `[rdi+rdx+0xc]` |

写：`[r11+rdi+4]` = `pDst[y][x]`。

抽头按系数分成 5 组：
- **G1**（12 抽头，系数 −1）：(−2,±1),(−2,±2),(+2,±1),(+2,±2),(±1,−2),(±1,+2)
- **G2**（4 抽头，系数 −2）：(0,±2),(±2,0)
- **G3**（4 抽头，系数 +8）：(±1,±1) 四个对角
- **G4**（4 抽头，系数 +10）：(0,±1),(±1,0) 四个正交
- **中心**（系数 +44）：(0,0)

## 5. 算式
```
w = (y & 1) ? const_0x469CD0 : const_0x469CC0        # 逐 lane，周期 2
                                                      # lane j 偶 -> 前者取 1/32；lane j 奇 -> 取 1/64
acc = -1 * sum(G1)  + -2 * sum(G2) + 8 * sum(G3) + 10 * sum(G4) + 44 * src[y][x]
dst[y][x] = w[lane] * acc
```

**权重的自洽性检查（关键结论）**：把 25 个抽头按 `(dy+dx)` 奇偶分成两类
- 同奇偶类（与中心同一棋盘格）：4×(−1) + 4×(−2) + 4×(8) + 44 = **64**
- 异奇偶类：8×(−1) + 4×(10) = **32**

而归一化因子恰好只有 1/64 和 1/32 两个值，按 `(行奇偶, lane 奇偶)` 交叉选取。这只有在**输入平面是半填充的棋盘格平面**（例如只有绿点非零的 G 平面，另一半为 0）时才成立：
- 输出点落在有样本的格子上 → 只有同奇偶类抽头非零 → 需除以 64；
- 输出点落在没样本的格子上 → 只有异奇偶类抽头非零 → 需除以 32。

因此这是一个**同时做「已有样本 5×5 低通」和「缺失样本插值」的统一核**，二者共用一份系数表，靠归一化因子切换。

**未定**：
- lane 奇偶 ↔ 实际列奇偶的对应，依赖 `Roi.x0` 为偶数（常量是 `{a,b,a,b}` 周期 2，SIMD 步进 8，所以 lane j 的列奇偶 = `(x0+j)` 的奇偶）。调度层若不保证 x0 偶，这里相位会翻。
- CFA 相位约定（绿点在 `(y+x)` 奇还是偶）无法从本函数单独确定，只能确定「1/32 用于 `(y+lane)` 偶、1/64 用于 `(y+lane)` 奇」。

## 7. 一句话定性
**棋盘格平面上的 5×5 Malvar 风格加权核**：正交 +10 / 对角 +8 / 轴向二环 −2 / 外圈 −1 / 中心 +44，按 CFA 相位除以 32 或 64——既是同色低通又是缺失点插值。
