# 361950 — vt[0xb8]：各向异性比值 → 置信度

函数体 0x140361950..0x140361b5b（`ret`）。文件后面 0x140361b60 起是两个别的函数
（一个瘦包装 + 0x140361c00 的大 kernel），不属于本函数。

## 1 签名

```
void __fastcall b8(void* this /*rcx，未用*/,
                   Plane* dst  /*rdx → r15*/,
                   Plane* aggH /*r8  → r13*/,
                   Plane* aggV /*r9  → r12*/,
                   Roi*   roi  /*[rsp+0x28]*/,
                   const Blk* P /*[rsp+0x30] → rdi，运行时 0x1405a8b68*/,
                   const Blk* a7 /*[rsp+0x38]，运行时 0x1405a8b48 —— **完全未被引用**/)
```

`mov [rsp+0x20], rbx` 在 push 之前（写 r9 的 home slot），随后 `push rdi/r12/r13/r15`
= 0x20，故 `[rsp+0x48]` = 原 `[rsp+0x28]` = 第 5 参 = roi，
`[rsp+0x50]` = 原 `[rsp+0x30]` = 第 6 参 = 参数块。

参数块布局在这里被**直接证实**：`cmp byte ptr [rdi], 0` 是 flag，
后面 `[rdi+1] [rdi+5] [rdi+9] [rdi+0xd]` = `p[0..3]`，即
`struct { uint8 flag; float p[]; }` 紧凑排列。

## 2 循环结构

两条独立的双重循环，按 flag 二选一。

* **flag == 0**（0x140361973..0x1403619dd）
  `for y in [roi.y0, roi.y1) / for x in [roi.x0, roi.x1)`，步进 1，
  `dst[y][x] = 0`（`mov dword ptr [rdx], r10d`，r10d = 0）。
* **flag != 0**（0x1403619f6..0x140361b30）—— 运行时走的就是这条（0x1405a8b68 的 flag = 1）
  同样的 `y ∈ [y0,y1)`、`x ∈ [x0,x1)`，步进 1。
  每行重取三条平面的 `data/height/stride`，越界或空指针时行基址置 0。
  内层每次迭代重读 `roi.x1`。

## 3 抽头几何

逐点，1×1。dst / aggH / aggV 同坐标。
`rax = dstRow + x0*4`、`rbp = aggHRow − dstRow` ⇒ `[rax+rbp]` = aggH 同点；
`r11 = aggVRow + x0*4`。

## 4 常量

| VA | 数值 | 角色 |
|---|---|---|
| 0x1404df190 | 8.0f | 分子分母共同的缩放系数 K（`mulss xmm4`） |
| 0x1404debbc | 1.0f | 折叠阈值 + 最终 `min` 的上界 |
| 0x140466678 | — | 退出时写入 `roi[0]` 的 vptr（两条路径都写） |

参数块 0x1405a8b68 实测：`flag = 1`，`p[0]=8.0, p[1]=0, p[2]=0, p[3]=0.5`
（笔记里 p[4] 之后的值来自越界读，块跨距只有 0x20 字节，见 35f1c0.md §4）。

| 偏移 | 记号 | 角色 |
|---|---|---|
| +0 | flag | 0 = 直接清零输出；非 0 = 走比值公式 |
| +1 | p[0] | 加到分子分母上的偏置（= 8.0，与 K 相同 ⇒ 比值化简为 (h+1)/(v+1)） |
| +5 | p[1] | 下限 / 保底值触发阈值，也是线性压缩的锚点（= 0） |
| +9 | p[2] | `ratio < p[1]` 时的保底输出（= 0） |
| +0xd | p[3] | 围绕 p[1] 的线性压缩增益（= 0.5） |

## 5 算式

```c
if (P->flag == 0) {
    for (y,x in roi) dst[y][x] = 0.0f;
} else {
    const float K = 8.0f, ONE = 1.0f;
    for (y = roi.y0; y < roi.y1; ++y)
      for (x = roi.x0; x < roi.x1; ++x) {
          float r = (K * aggH[y][x] + P->p[0])
                  / (K * aggV[y][x] + P->p[0]);
          float out;
          if (P->p[1] > r) {                 // comiss xmm1, xmm2; ja
              out = P->p[2];
          } else {
              if (r > ONE) r = ONE / r;      // 折叠成 <= 1（各向同性 → 1）
              r = (r - P->p[1]) * P->p[3] + P->p[1];
              out = fminf(ONE, r);
          }
          dst[y][x] = out;
      }
}
roi[0] = (void*)0x140466678;
```

代入实测参数（K = p[0] = 8.0, p[1] = p[2] = 0, p[3] = 0.5）：

```c
r = (aggH[y][x] + 1.0f) / (aggV[y][x] + 1.0f);
if (r > 1) r = 1/r;              // r ∈ (0, 1]
dst[y][x] = min(1.0f, 0.5f * r); // ⇒ 值域 (0, 0.5]
```

上界恰好 0.5，与实测值域 **[0.0006, 0.5]** 完全吻合（下界 0.0006 ⇒ H/V 比约 800:1）。

## 6 调用

叶函数，无 call。

## 7 一句话定性

把 aggH/aggV 的偏置比值折叠成「min(r, 1/r) ∈ (0,1]」的各向同性度，
再围绕 p[1] 用 p[3] 线性压缩并 clamp 到 1，输出一张 (0, 0.5] 的方向置信度图；
flag = 0 时整块清零。
