# 0x3b2b40 —— 0x3b2be0 的清零 + 建 ROI 包装(43 条)

> 绝对地址基址同样是 **0x7ff619850000**。`call 0x7ff619c02be0` → RVA **0x3b2be0**(§2.7 那个大函数),自洽。

## 1. 签名

栈帧:入口先把 rbx/rbp/r9 存进 home slot(不动 rsp),再 `push rsi/rdi/r14`(3×8=0x18)+ `sub rsp,0x50` = 0x68。
`[rsp+0x90]` ↔ 入口 `[rsp+0x28]` = **第 5 参数**。共 **5 个参数**,全部原样转发。

| # | 寄存器 | 用法 |
|---|---|---|
| 1 | rcx→rbp | 不解引用,直接透传给 0x3b2be0 的 rcx(疑似 `this`) |
| 2 | rdx→rdi | float 平面描述符 = **输出平面**;读 `+0x10`(数据)与 `+0xc`(字节数),用来清零 |
| 3 | r8→rsi | 透传(0x3b2be0 里是输入平面) |
| 4 | r9→rbx | **ROI 对象**;读 `+8/+0xc/+0x10/+0x14`(x0,y0,x1,y1),退出时写回 `+0` 的 vptr |
| 5 | [rsp+0x28] | 透传(0x3b2be0 里是调参块指针) |

注意参数 2 的 `+0xc` 被当成**字节数**传给 memset —— 说明这套 float 平面描述符是
`+0 宽 / +4 高 / +8 行距 / +0xc 总字节数 / +0x10 数据`。

## 2. 循环结构

**无循环。**纯调度/包装。

## 3. 抽头几何

无。不读像素。

## 4. 常量

| 指令 RVA | 目标 RVA | 数值 | 角色 |
|---|---|---|---|
| 3b2b77 | 0x466678 | vftable(6 槽) | 写进栈上那个 ROI 副本的 `+0`,退出时也写回参数 4 的 `+0` |

无浮点常量。

## 5. 算式

```
wrap(p1, p2_plane, p3, p4_roi, p5_params):
    if p2_plane->data != NULL:
        memset(p2_plane->data, 0, p2_plane->size_bytes)     # 清空输出图

    ROI tmp;                       # 栈上 0x18 字节
    tmp.vptr = &vtable_0x466678
    tmp.x0 = p4_roi->x0 ; tmp.y0 = p4_roi->y0
    tmp.x1 = p4_roi->x1 ; tmp.y1 = p4_roi->y1

    FUN_0x3b2be0(p1, p2_plane, p3, &tmp, p5_params)

    p4_roi->vptr = &vtable_0x466678                          # 还原/设置调用方对象的 vptr
```

`mov [rsp+0x20], rax`(rax = 第 5 参数)是**出参槽**:x64 下 `[rsp+0x20]` 正是被调用方的第 5 个参数位置。

## 6. 调用

* `3b2b72 call 0x7ff619ba8a2d` → RVA **0x358a2d**。参数 `(rcx=数据指针, edx=0, r8d=字节数)` —— 形状就是 `memset`。
* `3b2bba call 0x7ff619c02be0` → RVA **0x3b2be0**(§2.7 的四方向活动度函数)。直接调用,非虚表。

## 7. 一句话定性

**调度/包装**:清零输出图 + 在栈上重建一个 ROI 对象,然后把五个参数原样交给 0x3b2be0。本身不做任何算术。
