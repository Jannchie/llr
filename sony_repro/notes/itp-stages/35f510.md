# 35f510 — vt[0xf0]：从 W 平面产生 H / V 两张方向插值图

函数体 0x14035f510..0x14035f960（`ret`）。后面 0x14035f970 起是另一个函数。

## 1 签名

```
void __fastcall f0(void* this /*rcx，未用*/,
                   Plane* outH /*rdx，第 2 参*/,
                   Plane* outV /*r8， 第 3 参*/,
                   Plane* W    /*r9 → r13，唯一的输入*/,
                   Roi*   roi  /*[rsp+0x28] → r12*/,
                   Plane* m1   /*[rsp+0x30]，**未引用***/,
                   void*  task /*[rsp+0x38]，**未引用***/,
                   Plane* map3 /*[rsp+0x40]，**未引用***/)
```

`mov r11, rsp` 后把 rdx/r8/r9 存进各自 home slot；`push rsi/r12/r13`（0x18）+
`sub rsp,0x30` ⇒ rsp = E−0x48。于是 `[rsp+0x58]`=E+0x10=第 2 参，
`[rsp+0x60]`=E+0x18=第 3 参，`[rsp+0x68]`=E+0x20=第 4 参，`[rsp+0x70]`=E+0x28=第 5 参。
函数体内**从未出现** `[rsp+0x78] / [rsp+0x80] / [rsp+0x88]`，故第 6/7/8 参未用。

命名依据见 §5：第 2 参收水平方向的核，第 3 参收垂直方向的核。

## 2 循环结构

```
esi = y = roi.y0 + 2;   while (y < roi.y1 - 3)   y += 2   // 一次处理 y 和 y+1 两行
    edi = x = roi.x0 + 2;  while (x < roi.x1 - 2)  x += 2  // 一次处理 x 和 x+1 两列
```
每个 y 迭代里其实是两个独立的 x 内层循环：
* 内层 A（0x14035f6c0..0x14035f74c）写第 y 行的 x 和 x+1；
* 内层 B（0x14035f873..0x14035f904）写第 y+1 行的 x 和 x+1。

行基址一律用 `(x0+2)*4` 作为列起点（`lea r8,[rsi*4+8]`，rsi = x0）。
每行重取 `W.data / W.height / W.stride`，越界行基址置 0。
外层循环结尾重读 `roi.x0 / roi.y1`。

## 3 抽头几何

按 **(x + y) 的奇偶** 二选一（相对 (x0+2, y0+2) 起算）：

| (x+y) 相对奇偶 | outH（第 2 参） | outV（第 3 参） |
|---|---|---|
| 偶（图中记 e） | `(W[y][x−1] + W[y][x+1]) · 1/2` | `(W[y−1][x] + W[y+1][x]) · 1/2` |
| 奇（图中记 o） | `(W[y][x−2] + 6·W[y][x] + W[y][x+2]) · 1/8` | `(W[y−2][x] + 6·W[y][x] + W[y+2][x]) · 1/8` |

即：**偶格用相邻 1 像素的两抽头等权平均（无自身项）；奇格用相隔 2 像素的
[1, 6, 1]/8（自身占 0.75）**。这正是 Bayer 上 G 通道的处理方式 ——
G 缺失的格子纯插值，G 已知的格子做温和低通。

四个具体写入点（内层 A 的两次 + 内层 B 的两次）：

```
A: outV[y][x]    = (W[y+1][x]   + W[y-1][x]  ) * 0.5
A: outH[y][x]    = (W[y][x-1]   + W[y][x+1]  ) * 0.5
A: outV[y][x+1]  = (W[y-2][x+1] + W[y+2][x+1] + 6*W[y][x+1]  ) * 0.125
A: outH[y][x+1]  = (W[y][x-1]   + W[y][x+3]   + 6*W[y][x+1]  ) * 0.125
B: outV[y+1][x]  = (W[y-1][x]   + W[y+3][x]   + 6*W[y+1][x]  ) * 0.125
B: outH[y+1][x]  = (W[y+1][x-2] + W[y+1][x+2] + 6*W[y+1][x]  ) * 0.125
B: outV[y+1][x+1]= (W[y+2][x+1] + W[y][x+1]  ) * 0.5
B: outH[y+1][x+1]= (W[y+1][x+2] + W[y+1][x]  ) * 0.5
```

模板足迹：行 [y−2, y+3]、列 [x−2, x+3]，所以边界留了 2/3 像素。

## 4 常量

| VA | 数值 | 角色 |
|---|---|---|
| 0x1404deb28 | 0.5f (xmm3) | 两抽头等权平均的归一化 |
| 0x1404df118 | 6.0f (xmm4) | [1,6,1] 核的中心权 |
| 0x1404deadc | 0.125f (xmm5) | [1,6,1] 核的归一化（1+6+1 = 8） |
| 0x140466678 | — | 退出时写入 `roi[0]` 的 vptr |

无参数块，**没有任何可调参数**。

## 5 算式

```c
for (y = roi.y0 + 2; y < roi.y1 - 3; y += 2)
  for (x = roi.x0 + 2; x < roi.x1 - 2; x += 2)
    for (dy = 0; dy < 2; ++dy)
      for (dx = 0; dx < 2; ++dx) {
          int Y = y + dy, X = x + dx;
          if (((dx ^ dy) & 1) == 0) {            // (x+y) 同奇偶 → 距离 1 两抽头
              outH[Y][X] = 0.5f * (W[Y][X-1] + W[Y][X+1]);
              outV[Y][X] = 0.5f * (W[Y-1][X] + W[Y+1][X]);
          } else {                                // 否则 → 距离 2 的 [1,6,1]/8
              outH[Y][X] = 0.125f * (W[Y][X-2] + 6.0f*W[Y][X] + W[Y][X+2]);
              outV[Y][X] = 0.125f * (W[Y-2][X] + 6.0f*W[Y][X] + W[Y+2][X]);
          }
      }
roi[0] = (void*)0x140466678;
```

（反汇编里循环体是完全展开的 2×2，上面的四重循环只是等价改写。
`(dx ^ dy) & 1` 这一支的判定由展开顺序推得，不是显式比较。）

## 6 调用

叶函数，无 call。

## 7 一句话定性

对单张 W 平面做 CFA 感知的可分离插值，同时产出「纯水平估计」和「纯垂直估计」
两张平面：缺样点用相邻两抽头等权平均，有样点用 [1,6,1]/8 低通；无任何参数。
