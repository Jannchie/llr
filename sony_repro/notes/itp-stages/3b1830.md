# 0x3b1830 — 可分离 9 抽头 FIR（H/V 同时出图，系数按 CFA 相位切换，649 条指令）

## 1. 签名
`void f(p1 /*未用*/, PlaneF32* pDstH, PlaneF32* pDstV, PlaneF32* pSrc, Roi* pRoi, const float* coefA, const float* coefB)` —— **7 个参数**。

栈换算：`mov r11, rsp`（入口 rsp）→ `push r13` → `sub rsp, 0xd0`，故当前 `[rsp+X]` = 入口 `[rsp + X − 0xd8]`。

| 参数 | 位置 | 类型 | 用法 |
|---|---|---|---|
| 1 | rcx | ? | home slot 都没写，全函数未读 → `this` |
| 2 | rdx → `[rsp+0xe8]` | float32 平面描述符 | `+4`(高) `+8`(行距) `+0x10`(数据)。**水平 FIR 的输出** |
| 3 | r8 → `[rsp+0xf0]` | float32 平面描述符 | 同上。**垂直 FIR 的输出** |
| 4 | r9 → `[rsp+0xf8]`/r13 | float32 平面描述符 | `+4` `+8` `+0x10`。**唯一的读取源**，用 9 行 / 9 列 |
| 5 | `[rsp+0x100]` | ROI/任务对象 | `+8`=x0, `+0xc`=y0, `+0x10`=x1, `+0x14`=y1；退出前 `+0` 写 vftable |
| 6 | `[rsp+0x108]` | `const float[9]` | 系数表 A，按 `+0,+4,…,+0x20` 顺序读 9 个 |
| 7 | `[rsp+0x110]` | `const float[9]` | 系数表 B，同样 9 个 |

**没有栈保护 cookie，没有任何 rip 相对浮点常量**——全部系数都来自参数 6/7。

## 2. 循环结构
- 外层：`eax = y`（存 `[rsp+0x28]`），从 `Roi.y0 + 4` 到 `Roi.y1 − 4`，**按 2 展开**（每轮外循环处理 y 和 y+1，末尾 `y += 2`）。`y1` 每轮重载。
- 内层：**两段**，各自 8 像素步进：
  - 上半段（0x3b1ba0–0x3b1dc8）处理行 y，`[rsp+0x68]` 计数，从 `x0+4` 到 `x1−4`；
  - 下半段（0x3b2050–0x3b2274）处理行 y+1，`[rsp+4]` 计数，同样 `x0+4` → `x1−4`。
- 每段内部有两个连续的 FIR 块：先垂直 9 抽头写 pDstV，再水平 9 抽头写 pDstH。
- do-while，**无标量尾**；y 展开为 2 而循环长度未必是偶数，末尾可能多算一行（`y+1` 那半段不单独设防）。
- 每行都要重算 9 个源行指针 + 2 个目标行指针，全部带 `data==NULL / row>=height → 0` 保护，这就是为什么 649 条里绝大多数是地址算术。

## 3. 抽头几何
设当前输出像素 (y, x)，x 从 `x0+4` 起、步进 8。**只有两种一维抽头**：

**垂直块**（输出 → pDstV）

| 系数下标 | 行偏移 | 列偏移 |
|---|---|---|
| 0 | −4 | 0 |
| 1 | −3 | 0 |
| 2 | −2 | 0 |
| 3 | −1 | 0 |
| 4 | 0 | 0 |
| 5 | +1 | 0 |
| 6 | +2 | 0 |
| 7 | +3 | 0 |
| 8 | +4 | 0 |

上半段的寄存器实现（基址 `r12 = pSrc.row(y+2) + 4x`，`rdi = pSrc.row(y) + 4x`）：
`[r15+r12]`=−4, `[r9+r12]`=−3, `[r14+r12]`=−2, `[r8+rdi]`=−1, `[rdi]`=0, `[rsi+r12]`=+1, `[r12]`=+2, `[rdx+r12]`=+3, `[rax+r12]`=+4；写 `[rbx+r12]` = pDstV[y][x]。
下半段（中心 y+1，基址 `rdx = pSrc.row(y+3) + 4x`，`rax = pSrc.row(y+1) + 4x`）：`[r8+rdx]`=y−3 … `[rsi+rdx]`=y+5；写 `[r9+rdx]` = pDstV[y+1][x]。

**水平块**（输出 → pDstH）

| 系数下标 | 行偏移 | 列偏移 |
|---|---|---|
| 0 | 0 | −4 |
| 1 | 0 | −3 |
| 2 | 0 | −2 |
| 3 | 0 | −1 |
| 4 | 0 | 0 |
| 5 | 0 | +1 |
| 6 | 0 | +2 |
| 7 | 0 | +3 |
| 8 | 0 | +4 |

上半段用 `r11 = row(y) − row(y+2)` 加 −0x10/−0xc/−8/−4/0/+4/+8/+0xc/+0x10 九个字节位移（÷4 = 列偏移 −4..+4）实现；写 `[r12+r13-0x20]` = pDstH[y][x]。下半段同构，中心在 y+1。

## 4. 常量
**本函数内没有任何 rip 相对常量**（也没有 `__security_cookie`）。唯一的立即数是循环边界的 ±4、±3、±2、±1 和步进 8 / 0x20。

| RVA | 数值 | 角色 |
|---|---|---|
| 0x466678 | vftable（6 槽：0x12d1b0 / 0x12d44c / 0x12d444 / 0x12d1dc / 0x12d1e8 / 0x12d1f4） | 退出前 `mov [r10], rax` 写进参数 5 的 `+0` |

系数完全由参数 6（coefA）和参数 7（coefB）在运行时提供，各 9 个 float32。

## 5. 算式
核心技巧是 `vunpckhps ymm2, broadcast(P[i]), broadcast(Q[i])`：两个都是单值广播，unpckhps 之后得到 `[P,Q,P,Q,P,Q,P,Q]`——**偶 lane 取 P、奇 lane 取 Q**，即逐列奇偶切换系数。

而且上半段和下半段的两个源**互换**了：
- 行 y（上半段）：`vunpckhps ymm2, bc(coefB[i]), bc(coefA[i])` → 偶 lane = **coefB[i]**，奇 lane = **coefA[i]**
- 行 y+1（下半段）：`vunpckhps ymm2, bc(coefA[i]), bc(coefB[i])` → 偶 lane = **coefA[i]**，奇 lane = **coefB[i]**

于是系数选择是完整的 2×2 CFA 相位棋盘：

```
C(y, x) = ((y + x) 偶) ? coefB : coefA        # 相位常数取决于 x0/y0 的奇偶，见「未定」

for y in [y0+4, y1-4) step 2:
  for row in {y, y+1}:
    for x in [x0+4, x1-4) step 8:
      dstV[row][x] = sum_{k=-4..4} C(row,x)[k+4] * src[row+k][x]
      dstH[row][x] = sum_{k=-4..4} C(row,x)[k+4] * src[row][x+k]
```

无 abs、无 vcmpps、无 blend、无查表：**纯线性 FIR**，只有系数按相位选。

**未定**：
- `coefA` / `coefB` 与「绿点 / 红蓝点」的对应关系，本函数无法确定（lane 奇偶 = `(x − x0)` 的奇偶，需要调度层保证 `x0` 偶）。
- 9 个系数的具体数值在运行时由调用方填，本函数看不到。要拿数值必须去找填这两个数组的上游函数。

## 6. 调用
**一个 call 都没有**（连 `__security_check_cookie` 都没有，因为没开 cookie）。全内联。

## 7. 一句话定性
**可分离 9 抽头方向低通/插值核**：同一份相位相关系数分别沿 H 和 V 各卷一遍，一次写出两张方向候选图——方向性去马赛克里生成 H/V 候选（或方向代价的输入）的主力函数。
