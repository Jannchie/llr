# 0x3af8d0 —— 水平同色二阶差分 + 绿点掩码取绝对值

指令 132 条。模块基址 0x7ff619800000。

## 1. 签名

栈帧：`mov [rsp+8], rbx` → 7 个 push → `sub rsp,0xa0`，入口 rsp = R，当前 rsp = R-0xd8。
`mov rbx,[rsp+0x100]` = [R+0x28] = 第 5 参数。

| 参数 | 寄存器 | 用法 | 读到的字段 |
|---|---|---|---|
| p1 | rcx | **未使用**（入口后立刻被覆盖，疑似 this / 被优化掉） | — |
| p2 | rdx → r14 | float 平面描述符，**输出**：带符号二阶差分 | +0xc 字节大小(memset)、+4 高、+8 行距、+0x10 数据 |
| p3 | r8 → r15 | float 平面描述符，**输出**：\|二阶差分\| × 相位掩码 | +4 高、+8 行距、+0x10 数据 |
| p4 | r9 → r13 | float 平面描述符，**输入**源平面 | +4 高、+8 行距、+0x10 数据 |
| p5 | [R+0x28] → rbx | ROI 矩形对象（带虚表指针） | +8 = x0、+0xc = y0、+0x10 = x1、+0x14 = y1；返回前 `[rbx] = &vftable(0x466678)` |

开头 `memset(p2.data, 0, p2[+0xc])`，把整个输出平面清零（所以未覆盖的边界是 0）。

矩形字段的判定依据：ecx 从 [+0xc] 递增到 [+0x14]（行），列从 [+8]+2 到 [+0x10]-2（列，两边各留 2 像素余量）——水平滤波需要列余量、不需要行余量，正好吻合。同一个 0x466678 虚表在 0x3afac0 / 0x3b0f00 / 0x3b1040 / 0x3b0370 的同位置参数上也出现，五个函数共用同一矩形类型。

## 2. 循环结构

- 外层：`ecx = y0`，`while (ecx < y1)`，每次 +1。**没有行余量**。
- 内层：`r11d = x0+2`，`while (r11d < x1-2)`，每次 **+8**（一个 ymm，8 个 float）。指针 r10 每次 += 0x20。
- 没有标量尾循环；末尾一次向量写会越过 x1-2 最多 7 个 float（依赖 p2/p3 有 padding）。
- 内层每轮重新从 [rbx+0x10] 读 x1（编译器因别名无法提升），退出后重新读 [rbx+8]。
- 行指针都带「data==NULL 或 y>=height 就退化成 0」的守卫，属于边界检查残留。

行基址：`row = data + y*stride`；列起点 `r10 = row(p4) + 8 + 4*x0`，即 `&p4[y][x0+2]`。
`r9`、`r8` 在减去 rdx 后成为「p2 行基 - p4 行基」「p3 行基 - p4 行基」的差量，于是 `[r9+r10]` = `&p2[y][col]`，`[r8+r10]` = `&p3[y][col]`。

## 3. 抽头几何

只读 p4 一个输入平面，同一行：

| 输入 | 行偏移 | 列偏移(位移/4) | 位移 |
|---|---|---|---|
| p4 | 0 | -2 | -8 |
| p4 | 0 | 0 | 0 |
| p4 | 0 | +2 | +8 |

即同色（Bayer 隔一取一）水平三点。

## 4. 常量

| RVA | 值 | 载入方式 | 角色 |
|---|---|---|---|
| 0x4DEBBC | **1.0f** | `vbroadcastss ymm2` (3af92f) | 相位掩码里的「选中」值 |
| 0x4DEAE4 | **0.25f** | `vbroadcastss ymm5` (3af96e) | 二阶差分的归一化系数 |
| 0x469800 | **-0.0f** | `vbroadcastss ymm6` (3af977) | `vandnps` 取绝对值的掩码 |
| 0x559440 | — | `[rip+0x1a9b41]` | __security_cookie |

另外有一串对 [rbp+0x40] 的死存储：`0x3f800000`(1.0)、`0`、`0x3e800000`(0.25)、`0x80000000`(-0.0)——正好是上面三个常量加 0，是源码里字面量被物化后残留的存储，可作交叉验证。

相位掩码的构造（3af93b–3af95a）：
```
ymm2 = broadcast(1.0); ymm1 = 0
maskA = vunpcklps(ymm2, 0) = [1,0,1,0, 1,0,1,0]   → 存 [rbp]
maskB = vunpckhps(0, ymm2) = [0,1,0,1, 0,1,0,1]   → 存 [rbp+0x20]
每行：ymm4 = (y 为奇数) ? maskA : maskB
```
lane0 对应列 x0+2。若 x0 为偶数，则「偶行选奇列 / 奇行选偶列」——在 RGGB 上正好是**绿色像素位置**。

## 5. 算式

```
memset(p2, 0)
for y in [y0, y1):
    m = (y & 1) ? [1,0,1,0,...] : [0,1,0,1,...]        # 绿点掩码
    for x in [x0+2, x1-2) step 8:                      # 8 lane 一次
        L      = 0.25 * (2*p4[y][x] - p4[y][x-2] - p4[y][x+2])
        p2[y][x] = L
        p3[y][x] = |L| * m[x]
```
`|L|` 由 `vandnps(-0.0, L)` 实现。

## 6. 调用

| 目标 RVA | 形式 | 说明 |
|---|---|---|
| 0x3a8a2d | 直接 call | memset(p2.data, 0, size) |
| 0x3a5630 | 直接 call | __security_check_cookie |

无虚表调用。

## 7. 一句话定性

**水平方向的同色二阶差分（Hamilton–Adams 校正项）+ 绿点位置上的方向代价**：p2 输出带符号的 0.25·(2c−l−r)，p3 输出它的绝对值并只保留绿色采样点，供后续方向判据用。
