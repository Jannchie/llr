# 0x3b2920 —— 两对平面的逐点中点(151 条)

> 注:反汇编文本里的绝对地址用的基址是 **0x7ff619850000**(不是 0x7ff619800000)。
> 例:`call 0x7ff619ba5630` → RVA `0x355630`;`jae 0x7ff619c02b19` → 本函数内的 `3b2b19`。
> 下文所有 RVA 都按这个基址换算。rip 相对常量按"下一条指令 RVA + 位移"算,与列首 RVA 自洽。

## 1. 签名

栈帧:`push r12/r13/r14/r15`(4×8=0x20)+ `sub rsp,0x48` = 0x68。
`[rsp+X]` ↔ 入口 `[rsp + X-0x68]`。于是 `[rsp+0x90]/0x98/0xa0/0xa8` = 入口 `[rsp+0x28]/0x30/0x38/0x40` = **第 5/6/7/8 参数**。共 **8 个参数**。

| # | 寄存器/槽 | 用法 |
|---|---|---|
| 1 | rcx | **完全没被读过**(进函数后 ecx 立刻被 `[r15+0xc]` 覆盖)。八成是 `this`。 |
| 2 | rdx→r13 | float 平面描述符,**输出 A** |
| 3 | r8→r12 | float 平面描述符,**输出 B** |
| 4 | r9 | float 平面描述符,输入 A1 |
| 5 | [rsp+0x28]→r8 | float 平面描述符,输入 B1 |
| 6 | [rsp+0x30]→r14 | float 平面描述符,输入 A2 |
| 7 | [rsp+0x38]→[rsp] | float 平面描述符,输入 B2 |
| 8 | [rsp+0x40]→r15 | **ROI/矩形对象**,不是平面 |

平面描述符读的字段:`+0x10` 数据指针、`+4` 高(行边界检查)、`+8` 行距(字节,`imul y, [desc+8]`)。
六个平面的行基址一律用同一段模板算:`data==0 → 0`;`y >= [desc+4] → 0`;否则 `data + y*[desc+8]`。

ROI 对象(参数 8)字段:`+8` = x0、`+0xc` = y0、`+0x10` = x1、`+0x14` = y1;
退出前 `mov [r15], rax`,写回 vftable `0x466678`(五个函数都写同一个,见 §6)。

## 2. 循环结构

两层,无标量尾巴。

* 外层:`ecx = y`,从 `[roi+0xc]`(y0)到 `[roi+0x14]`(y1),`inc ecx`,`y < y1` 继续。
* 内层:`r11d = x`,从 `[roi+8]`(x0)到 `[roi+0x10]`(x1),**每次 +8**(一个 ymm = 8 个 float),没有余数处理 —— 写满整块 ymm,可能越过 x1 最多 7 个像素。
* 每行开头重算 6 个行基址;进内层前把它们全部改写成"相对 rax 的差值"(`rax = &out_A[y][x]`),循环里只推进 `rax`/`rsi` 两个游标(各 +0x20)。

## 3. 抽头几何

只有 (0,0) 一个抽头 —— **纯逐点**,没有邻域。

| 输入 | (行偏移, 列偏移) |
|---|---|
| 参数 4 (A1) | (0, 0) |
| 参数 6 (A2) | (0, 0) |
| 参数 5 (B1) | (0, 0) |
| 参数 7 (B2) | (0, 0) |

## 4. 常量

| 指令 RVA | 目标 RVA / VA | 数值 | 角色 |
|---|---|---|---|
| 3b292c | 0x559440 / 0x140559440 | (栈 cookie) | `__security_cookie` |
| 3b298b | **0x4DEB28** / 0x1404deb28 | **0.5** | `vbroadcastss ymm3`,两抽头平均的系数 |
| 3b2b19 | 0x466678 / 0x140466678 | (vftable) | 退出时写回 ROI 对象的 `+0` |

另有一条 `3b29a3 mov dword ptr [rsp+0x20], 0x3f000000` —— 死存储,值就是 0.5,和上面那个 rip 常量一致(编译器把同一个常量也落了一份标量到栈上)。

## 5. 算式

```
for y in [y0, y1):
  for x in [x0, x1) step 8:
    out_A[y][x..x+7] = 0.5f * (in_A1[y][x..x+7] + in_A2[y][x..x+7])   # 参数2 = 0.5*(参数4 + 参数6)
    out_B[y][x..x+7] = 0.5f * (in_B1[y][x..x+7] + in_B2[y][x..x+7])   # 参数3 = 0.5*(参数5 + 参数7)
```

对应关系是从指针差反推的,确凿:
`rax = &p2[y][x]`、`rsi = &p6[y][x]`、`r10+rax = p4[y][x]`、`rdi+rax = &p3[y][x]`、`r9+rax = p5[y][x]`、`rdx+rax = p7[y][x]`。

## 6. 调用

* `3b2b2b call 0x7ff619ba5630` → RVA **0x355630**,`__security_check_cookie`。直接调用。
* 无虚表槽调用。
* `0x466678` 是一张 6 槽 vftable(`0x14012d1b0 / d44c / d444 / d1dc / d1e8 / d1f4`),本组五个函数退出时都把它写进最后那个 ROI 对象 —— 是同一个小对象类型(带 vptr 的矩形/窗口)。

## 7. 一句话定性

**纯逐点、两路并行的中点混合**(两对平面各取 0.5 平均),没有判据、没有邻域、没有查表 —— 典型的"金字塔/多尺度里把两级或两相位合并"的胶水级。
