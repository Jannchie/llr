## 与 35d3a0 的关系

**没有关系。** 35d3a0 结束于 0x14035d3d4，之后 `int3` 填充到 0x14035d3e0，
35d3e0 是下一个独立函数。两者之间没有 call，签名完全不同
（35d3a0 是三 float 入寄存器的叶函数，35d3e0 吃 7 个以上的平面/结构指针、

## 1 签名

```
void __fastcall f(void* this /*rcx，未用*/,
                  Plane* dst1 /*rdx → r12*/,
                  Plane* dst2 /*r8  → r15*/,
                  Plane* src1 /*r9  → r13*/,
                  Plane* src2 /*[rbp+0x90] → rbx，第 5 参*/,
                  Roi*   roi  /*[rbp+0x98] → rdi，第 6 参*/,
                  const Blk* P /*[rbp+0xa0]，第 7 参*/)
```

栈推导：`mov [rsp+8], rbx`；`push rbp/rsi/rdi/r12/r13/r14/r15`（7×8 = 0x38）；
`lea rbp, [rsp-0x30]` ⇒ rbp = E − 0x68；`sub rsp, 0x130`。
故 `[rbp+0x90] = E+0x28` = 第 5 参，`[rbp+0x98] = E+0x30` = 第 6 参，
`[rbp+0xa0] = E+0x38` = 第 7 参。栈 cookie 取自 0x140559440，存 `[rbp+0x20]`。

第 7 参同样是 `{uint8 flag; float p[]}`：`cmp byte ptr [rax], 0` / `jne`。

      dst1[roi.y0+r14][roi.x0+edx] = src1[roi.y0+r14][roi.x0+edx];   // 32 位整数搬运

for (r10 = 0; r10 < roi.y1 - roi.y0; ++r10)          // 循环 2

0x14035db8f 收尾。
