# 0x3b0370 —— 4 平面色差场构造：直接差分 + 方向自适应加权插值（纯标量）

指令 726 条。**全部是 `movss/subss/mulss/addss` 标量**，没有一条 ymm/xmm 打包运算——这是本组里唯一不向量化的函数。

## 1. 签名

入口 `mov rax, rsp` 后把 rcx/rdx/r8/r9 存进 home slot，随后 8 个 push + `sub rsp,0x118`，当前 rsp = R-0x158。
所以 `[rsp+0x160+8k]` ↔ `[R+0x8+8k]` ↔ 第 (k+1) 个参数。共 **10 个参数**。

| 参数 | 栈上位置 | 用法 |
|---|---|---|
| p1 | [rsp+0x160] | **this 指针**：每个像素两次 `call qword ptr [vptr+0x170]`（虚表槽 +0x170） |
| p2 | [rsp+0x168] | float 平面描述符，**输出** A（+4 高、+8 行距、+0x10 数据） |
| p3 | [rsp+0x170] | float 平面描述符，**输出** B |
| p4 | [rsp+0x178] | float 平面描述符，**输出** C |
| p5 | [rsp+0x180] | float 平面描述符，**输出** D |
| p6 | [rsp+0x188] | float 平面，**输入**，取 y-1 / y / y+1 三行（垂直组第一支） |
| p7 | [rsp+0x190] | float 平面，**输入**，只取 y 行、列 c-1..c+2（水平组第一支） |
| p8 | [rsp+0x198] | float 平面，**输入**，取 y-1 / y / y+1 三行（垂直组第二支） |
| p9 | [rsp+0x1a0] | float 平面，**输入**，只取 y 行、列 c-1..c+2（水平组第二支） |
| p10 | [rsp+0x1a8]（也在 r9） | ROI 矩形对象：+8=x0、+0xc=y0、+0x10=x1、+0x14=y1；返回前 `[r9] = &vftable(0x466678)` |

p6/p8 的高度字段通过 `lea r13,[r11+4]` / `lea r9,[r8+4]` 变成指针再解引用（编译器把 `+4`、`+8` 提成了地址），本质仍是 +4 高、+8 行距、+0x10 数据。

**没有 memset，没有安全 cookie。**

## 2. 循环结构

两层，都是 **步长 2**，一次处理一个 2×2 的 Bayer 方格，展开成四个代码块：

- 外层行：`esi = y0+2`；`while (esi < y1-2)`；**每次 +2**。函数体里先做行 `y = esi`（0x3b03f0–0x3b0981），再做行 `y+1 = ebp`（0x3b09a1–0x3b0e96），两半各自重建全部行指针。
- 内层列（两半各一个）：`c = x0+2`；`while (c < x1-2)`；**每次 +2**，块内分别处理列 `c` 与 `c+1`。
- 所以四个代码块 = (行 y, 列 c) / (行 y, 列 c+1) / (行 y+1, 列 c) / (行 y+1, 列 c+1)。
- 没有向量化、没有尾循环。行方向和列方向都留 2 像素余量。
- 每个像素 **2 次虚调用**，一个 2×2 方格 8 次。
- 所有行指针都带「data==NULL 或 y>=height 就退化」的守卫（退化后指针变成纯列偏移，属边界检查残留）。

## 3. 抽头几何

以当前输出行 `y`、列 `c` 为原点（后半段把 y 换成 y+1，几何完全相同）：

**垂直组（p6 / p8）**——两者抽头集合完全一致：

| 输入 | 行偏移 | 列偏移 |
|---|---|---|
| p6 / p8 | -1 | 0 |
| p6 / p8 | -1 | +1 |
| p6 / p8 | 0 | 0 |
| p6 / p8 | 0 | +1 |
| p6 / p8 | +1 | 0 |
| p6 / p8 | +1 | +1 |

**水平组（p7 / p9）**——只在本行：

| 输入 | 行偏移 | 列偏移 |
|---|---|---|
| p7 / p9 | 0 | -1 |
| p7 / p9 | 0 | 0 |
| p7 / p9 | 0 | +1 |
| p7 / p9 | 0 | +2 |

（列 c 用 c-1/c+1 作左右邻居，列 c+1 用 c/c+2 作左右邻居。）

输出 p2..p5 只写本行的列 c 和 c+1。

## 4. 常量

| RVA | 值 | 载入方式 | 角色 |
|---|---|---|---|
| 0x4DEBBC | **1.0f** | `movss xmm11, [rip+0x12e7da]` (3b03d9) | 凸组合的 1：`w*a + (1-w)*b` |

**全函数只有这一个 rip 相对浮点常量。** 另有 `lea rax,[rip+0xb57ba]` → 0x466678（ROI 虚表）。

## 5. 算式

记 `V(y,x) = p6[y][x] - p8[y][x]`（垂直组差），`H(y,x) = p7[y][x] - p9[y][x]`（水平组差），
`f(a, b, ctr)` = 虚表槽 +0x170 的函数，返回一个权重 w（用法是 `w*一侧 + (1-w)*另一侧`，故应落在 [0,1]）。

四个块逐字还原（符号严格按反汇编，**注意符号随 (x+y) 奇偶翻转**）：

**块 A — (y, c)**
```
w1 = f(p6[y-1][c],  p6[y+1][c],  p8[y][c])
w2 = f(p7[y][c-1],  p7[y][c+1],  p9[y][c])
p2[y][c] =  V(y,c)                                    # 直接
p3[y][c] =  H(y,c)                                    # 直接
p4[y][c] =  w1 * (-V(y-1,c)) + (1-w1) * (-V(y+1,c))   # 垂直插值
p5[y][c] =  w2 * (-H(y,c-1)) + (1-w2) * (-H(y,c+1))   # 水平插值
```

**块 B — (y, c+1)**
```
w1 = f(p9[y][c],    p9[y][c+2],  p7[y][c+1])
w2 = f(p8[y-1][c+1],p8[y+1][c+1],p6[y][c+1])
p2[y][c+1] = -V(y,c+1)                                       # 直接
p5[y][c+1] = -H(y,c+1)                                       # 直接
p3[y][c+1] =  w1 * H(y,c) + (1-w1) * H(y,c+2)                # 水平插值
p4[y][c+1] =  w2 * V(y-1,c+1) + (1-w2) * V(y+1,c+1)          # 垂直插值
```

**块 C — (y+1, c)**
```
w1 = f(p8[y][c],    p8[y+2][c],  p6[y+1][c])
w2 = f(p9[y+1][c-1],p9[y+1][c+1],p7[y+1][c])
p2[y+1][c] =  w1 * V(y,c) + (1-w1) * V(y+2,c)                # 垂直插值
p5[y+1][c] =  w2 * H(y+1,c-1) + (1-w2) * H(y+1,c+1)          # 水平插值
p3[y+1][c] = -H(y+1,c)                                       # 直接
p4[y+1][c] = -V(y+1,c)                                       # 直接
```

**块 D — (y+1, c+1)**
```
w1 = f(p6[y][c+1],  p6[y+2][c+1], p8[y+1][c+1])
w2 = f(p7[y+1][c],  p7[y+1][c+2], p9[y+1][c+1])
p2[y+1][c+1] =  w1 * (-V(y,c+1))   + (1-w1) * (-V(y+2,c+1))     # 垂直插值
p3[y+1][c+1] =  w2 * (-H(y+1,c))   + (1-w2) * (-H(y+1,c+2))     # 水平插值
p4[y+1][c+1] =  V(y+1,c+1)                                      # 直接
p5[y+1][c+1] =  H(y+1,c+1)                                      # 直接
```

**归纳出的不变量**（令 S(x,y) = (-1)^(x+y)）：

- p2 与 p4 都装 `S·V`，p3 与 p5 都装 `S·H`。
- **p2 / p3 在偶行是直接值、在奇行由方向加权插值补全；p4 / p5 恰好相反**（奇行直接、偶行插值）。
- 垂直插值只用上下两个同列邻居，水平插值只用左右两个同行邻居，权重由 `f` 现算。
- 「p6/p8 配垂直邻居、p7/p9 配水平邻居」这条对应关系在四个块里没有例外。

**未定**：
- `f`（虚表槽 +0x170）的具体实现未反汇编，只知它取 (两侧值, 中心值) 三个 float 返回一个权重；无法确认是否夹到 [0,1]。
- p6/p7/p8/p9 的语义身份（哪一支是低通、哪一支是拉普拉斯校正、还是绿/非绿估计）**未定**，本函数里看不出来；只能确定 p6↔p8 成对、p7↔p9 成对，且两对分别对应垂直/水平方向。
- 输出 p2..p5 的通道含义（例如 R-G / B-G）**未定**。

## 6. 调用

| 目标 | 形式 | 说明 |
|---|---|---|
| `[*(p1) + 0x170]` | **虚表槽 +0x170**，每像素 2 次 | 方向权重函数 `f(this, a, b, ctr) -> float`；参数按 Win64 走 rcx=this、xmm1、xmm2、xmm3，返回 xmm0 |

**没有任何直接 call**（连 __security_check_cookie 都没有，本函数不带 cookie）。

## 7. 一句话定性

**方向自适应的色差场填充**：对 Bayer 的每个 2×2 相位，把两条方向差分（垂直 p6−p8、水平 p7−p9）在「本相位」直接落盘，在「另一相位」用虚函数算出的边缘权重在上下 / 左右两邻居之间做凸混合补全——是混合 + 判据（判据外包给虚函数）的组合，而不是低通或查表。
