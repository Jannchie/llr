# 35d3a0 — 两抽头逆距离权重（vt[0x170]）

原始 `disasm_35d3a0.txt` 只有 11 条，**在 `ret` 处被截断**。用 `disasm_fn.py` /
`read_rdata.py` 补读 0x14035d3cc..0x14035d3d8 的原始字节后补齐了 else 分支：

```
0x14035d3cc  c3              ret
0x14035d3cd  f3 0f 5e d1     divss   xmm2, xmm1
0x14035d3d1  0f 28 c2        movaps  xmm0, xmm2
0x14035d3d4  c3              ret
0x14035d3d5  cc cc ...       int3 填充到 0x14035d3e0
```

（capstone 在 `ret` 后停下来了，所以文件里看不到这 8 个字节；`jp/jne 0x14035d3cd`
的跳转目标正是这里。）

## 1 签名

```
float __fastcall f(void* this /*rcx，未用*/, float a /*xmm1*/, float b /*xmm2*/, float c /*xmm3*/)
```

叶函数，无栈帧、无调用、无内存写。返回值在 xmm0。

## 2 循环结构

无循环。单像素标量函数，全长 0x35 字节。

## 3 抽头几何

无。三个 float 由调用方（0x3b0370）从三条平面上取好后直接传寄存器。
0x3b0370 里第一处调用点（0x3b0740）的取数：
`xmm1 = *r12`、`xmm2 = *rdi`、`xmm3 = *r15`（r15 是中心）。

## 4 常量

| VA | 数值 | 角色 |
|---|---|---|
| 0x1404e02a0 | 4×0x7fffffff | float 绝对值掩码（andps） |
| 0x1404deb28 | 0.5f | 分母为 0（两抽头都等于中心）时的兜底权重 |

## 5 算式

```c
float f(float a, float b, float c) {
    float da = fabsf(a - c);
    float db = fabsf(b - c);
    float s  = da + db;
    if (s == 0.0f)          // ucomiss + jp/jne：NaN 也走 else
        return 0.5f;
    return db / s;          // 注意分子是 *第二个* 参数的距离
}
```

## 6 调用

无（叶）。被 0x3b0370 每像素调两次（0x3b0740 / 0x3b076e，以及后面 0x3b087e /
0x3b08ad / 0x3b0c71 / 0x3b0c9b / 0x3b0d95 / 0x3b0dbe 共 8 处）。

调用方 0x3b07a7 起的用法（xmm11 = 1.0f，xmm6 = 本函数返回值 w）：

```
out = (1 - w) * D_b + w * D_a      // D_a 与参数 a 同侧，D_b 与参数 b 同侧
```

因为 `w = db/(da+db)`，**a 侧拿到的权重正比于 b 到中心的距离** —— 也就是
离中心越近的那个抽头权重越大。这是标准的两抽头逆距离（inverse-distance）混合。

## 7 一句话定性

按「与中心值的绝对差」做两抽头逆距离归一化，返回给第一个抽头的权重；
两抽头都等于中心时退化为 0.5（等权）。
