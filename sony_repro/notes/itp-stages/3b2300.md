# 0x3b2300 — 双权重取 max 后做 lerp 混合（134 条指令）

## 1. 签名
`void f(p1 /*未用*/, PlaneF32* pDst, PlaneF32* pA, PlaneF32* pB, PlaneF32* pW1, PlaneF32* pW2, Roi* pRoi)` —— **7 个参数**。

栈换算：push rsi/r12/r13/r15（4 个）+ `sub rsp, 0x38`，故当前 `[rsp+X]` = 入口 `[rsp + X − 0x58]`。

| 参数 | 位置 | 类型 | 用法 |
|---|---|---|---|
| 1 | rcx | ? | 全函数未读 → `this` |
| 2 | rdx → r15 | float32 平面描述符 | `+4`(高) `+8`(行距) `+0x10`(数据)。**写入目标** |
| 3 | r8 → r13 | float32 平面描述符 | 同上。混合的 **A 端**（权重 0 时取它） |
| 4 | r9 → r12 | float32 平面描述符 | 同上。混合的 **B 端**（权重 1 时取它） |
| 5 | `[rsp+0x80]` (入口 `[rsp+0x28]`) | float32 平面描述符 | 同上。**权重图 1** |
| 6 | `[rsp+0x88]` (入口 `[rsp+0x30]`) → `[rsp+0]` | float32 平面描述符 | 同上。**权重图 2** |
| 7 | `[rsp+0x90]` (入口 `[rsp+0x38]`) → rsi | ROI/任务对象 | `+8`=x0, `+0xc`=y0, `+0x10`=x1, `+0x14`=y1；退出前 `+0` 写 vftable |

5 个平面描述符都走同一套 `data==NULL || y>=height → 行基址取 0` 的保护。

## 2. 循环结构
- 外层：`ecx = y`，从 `Roi.y0`（`[rsi+0xc]`）到 `Roi.y1`（`[rsi+0x14]`），步进 1。**y 不收缩**。
- 内层：`r11d = x`，从 `Roi.x0` 到 `Roi.x1`（每轮重载 `[rsi+0x10]`），**步进 8**。**x 也不收缩**。
- do-while，**无标量尾**，最多多写 7 像素。
- 整个 ROI 全覆盖，说明这是逐点操作，不需要边界余量。

## 3. 抽头几何
全部是**同点**读取（行偏移 0、列偏移 0），没有任何邻域。
基址：`rdi = pW1.row(y) + 4*x0`，`rax = pA.row(y) + 4*x0`，两者同步 +0x20；其余用差值寻址：
`rdx = pW2.row(y) − pA.row(y)`，`r9 = pB.row(y) − pA.row(y)`，`rbx = pDst.row(y) − pA.row(y)`。

| 输入 | 行偏移 | 列偏移 | 汇编 |
|---|---|---|---|
| pW1 | 0 | 0 | `[rdi]` |
| pW2 | 0 | 0 | `[rdx+rax]` |
| pB | 0 | 0 | `[r9+rax]` |
| pA | 0 | 0 | `[rax]` |
| **写 pDst** | 0 | 0 | `[rbx+rax]` |

## 4. 常量
| RVA | VA | 数值 | 角色 |
|---|---|---|---|
| 0x4DEBBC | 0x1404DEBBC | **1.0** | `vbroadcastss ymm4`，用于 `1 − w` |
| 0x559440 | — | `__security_cookie` | 栈保护 |
| 0x466678 | 0x140466678 | vftable（6 槽） | 退出前写进参数 7 的 `+0` |

死存 `mov dword ptr [rsp+0x10], 0x3f800000` = 1.0f，与广播常量印证。

## 5. 算式
```
for y in [y0, y1):
  for x in [x0, x1) step 8:
    w   = max(W1[y][x], W2[y][x])          # vmaxps
    dst[y][x] = (1 - w) * A[y][x] + w * B[y][x]
```
逐指令对照：
```
ymm0 = W1;  ymm3 = max(ymm0, W2);  ymm0 = ymm3 * B;
ymm2 = 1.0 - ymm3;  ymm1 = ymm2 * A;  ymm1 = ymm1 + ymm0;  store
```

**注意**：函数**不做任何 clamp**。若 `max(W1,W2)` 超出 `[0,1]`，结果就是外插。所以权重图必须由上游保证已归一到 `[0,1]`。取 `max` 而非相加/相乘，说明两张权重图是「两个独立的触发条件，任一命中就往 B 端拉」——典型的伪影/边缘保护掩膜合并。

## 6. 调用
- `call 0x7ff619ba5630` → RVA **0x3a5630** = `__security_check_cookie`。
- 无虚表调用。

## 7. 一句话定性
**纯逐点的混合（lerp）算子**：把两张掩膜取逐点最大值当权重，在 A、B 两张候选图之间线性插值——去马赛克末端把「安全结果」和「锐利结果」按伪影强度融合的收尾步骤。
