# 0x3b3910 —— CFA 相位感知的 5x5 同色低通 / 稀疏平面补全(207 条)

> 绝对地址基址 **0x7ff619850000**。

## 1. 签名

栈帧:`mov [rsp+8], rbx` → `push rbp/rsi/rdi/r12/r13/r14/r15`(7×8=0x38)+ `sub rsp,0xa0`,再 `lea rbp,[rsp+0x20]` / `and rbp,~0x1f` 做 32 字节对齐的帧指针。
**只用寄存器参数,4 个参数**(没有任何 `[rsp+0x28]` 以上的读取)。

| # | 寄存器 | 用法 |
|---|---|---|
| 1 | rcx | **完全没被读过**。疑似 `this`。 |
| 2 | rdx→r15(并存 `[rbp]`) | float 平面描述符,**输出**。读 `+0x10` 数据、`+4` 高、`+8` 行距 |
| 3 | r8 | float 平面描述符,**输入**。读 `+0x10` 数据、`+4` 高、`+8` 行距 |
| 4 | r9→rdi | **ROI 对象**:`+8`=x0、`+0xc`=y0、`+0x10`=x1、`+0x14`=y1;退出写回 `+0` = vftable 0x466678 |

注意 ROI 的 `+0x10 / +0x14` 在这里当 **x1 / y1** 用(`cmp x, [rdi+0x10]`、`sub eax,[rdi+0x14]`),
不是"行距/高"—— 和平面描述符是两种不同的对象,别混。

## 2. 循环结构

两层。

* 外层 `edx = y`:从 `y0+2` 开始,条件 `y < y1-2`(`mov eax,[rdi+0x14]; sub eax,2; cmp edx,eax; jb`)。步长 1。
  另有一个跟随变量 `[rbp+0x60] = y+2`,每行 `inc`。
* 每行开头 **先标量拷贝最左两列**:`out[y][x0] = in[y][x0]`、`out[y][x0+1] = in[y][x0+1]`,然后两个游标 `r9`(输入行 y)、`r12`(输出行 y)各 `+8`。
* 内层 `r15d = x`:从 `x0+2` 开始,条件 `x < x1-2`,**每次 +8**(一个 ymm)。无标量余数循环。
* 内层结束后 **再标量拷贝两列**:`out[y][x_end] = in[y][x_end]`、`out[y][x_end+1] = in[y][x_end+1]`。
  → 边界策略是"左右各留 2 列直接复制,中间做卷积"。

行基址一律用同一模板:`data==0 → 0`;`row >= [desc+4] → 0`;否则 `data + row*[desc+8]`。
本函数用了输入平面的 **5 行**:y-2、y-1、y、y+1、y+2。

## 3. 抽头几何

内层游标(k = 第几个 8 像素块,x = x0+2+8k):

| 寄存器 | 指向 | 说明 |
|---|---|---|
| `rsi` | `&in[y-2][x]` | 主游标,+0x20/迭代 |
| `rbx + rsi` | `&in[y-1][x]` | rbx = row(y-1) − row(y-2) |
| `r14 + rsi` | `&in[y+1][x]` | r14 = row(y+1) − row(y-2) |
| `rcx` | `&in[y+1][x-2]` | 等价于 `[r14+rsi-8]`,编译器另开的指针 |
| `r11 + rsi` | `&in[y+2][x]` | r11 = row(y+2) − row(y-2) |
| `r9` | `&in[y][x]` | 独立游标,+0x20/迭代 |
| `r12` | `&out[y][x]` | 输出,+0x20/迭代 |

按字面反汇编列出来的抽头(列偏移 = 位移/4):

| 行偏移 | 权 6 的列偏移 | 权 1 的列偏移 | 权 36 |
|---|---|---|---|
| −2 | 0 | −2, −1, +1, +2 | — |
| −1 | −1, 0, +1 | −2, +2 | — |
| **0**(`r9` 基址) | **0, +1, +3, +4** | — | **+2** |
| +1 | −1, 0, +1 | −2, +2 | — |
| +2 | 0 | −2, −1, +1, +2 | — |

**⚠️ 第 0 行(`r9`)的列偏移比其余四行整体右移了 2**:其余行用 `-8/-4/0/+4/+8`,
而 `r9` 用 `0/+4/+8/+0xc/+0x10`。两个游标在 k=0 时都指向 `列 x0+2`(`r9` 因为
`3b3a21 add r9,8`、`rsi` 因为 `3b3ad8 add rsi,8`),所以这是**字面上真实存在的 +2 列偏移**。
若把它按对称形式读(即 `r9` 概念上落在 `列 x−2`),整张核就是下面这个漂亮的 5×5:

```
         x-2  x-1   x   x+1  x+2
y-2       1    1    6    1    1
y-1       1    6    6    6    1
y         6    6   36    6    6
y+1       1    6    6    6    1
y+2       1    1    6    1    1        总和 = 120
```

两种读法的**棋盘拆分完全一样**(移 2 列不改变 dx+dy 的奇偶),所以下面的 32/88 结论对两者都成立。
**哪一种是作者本意:未定。**对称版更可信,但反汇编文本支持的是 +2 版。

## 5. 算式

```
n32 = 1/32 ; n88 = 1/88

for y in [y0+2, y1-2):
    out[y][x0]   = in[y][x0]
    out[y][x0+1] = in[y][x0+1]
    for x in [x0+2, x1-2) step 8:
        A = 12 个"权 6"抽头之和        # 8 邻域 + 上下左右距离 2 的四个(对称读法)
        B = 12 个"权 1"抽头之和        # 5x5 的四角区
        C = 中心抽头
        n = ((x ^ y) & 1) == 0 ? n32 : n88          # cmove,广播成整条 ymm
        out[y][x..x+7] = (6*A + B + 36*C) * n
    out[y][x_end]   = in[y][x_end]
    out[y][x_end+1] = in[y][x_end+1]
```

**为什么是 32 和 88。**把上面那个 5×5 核按 `(dx+dy)` 的奇偶劈开:

* `dx+dy` 为奇:`(0,±1)`+`(±1,0)` 各 6 → 24;`(±2,±1)`、`(±1,±2)` 各 1 → 8。**合计 32**。
* `dx+dy` 为偶:中心 36;`(0,±2)`+`(±2,0)` 各 6 → 24;`(±2,±2)` 各 1 → 4;`(±1,±1)` 各 6 → 24。**合计 88**。
* 32 + 88 = 120 = 全核和。

也就是说 **输入平面是稀疏的马赛克**:只有一个棋盘子格上有值,另一半是 0。
归一化系数必须等于"落在非零子格上的权重之和的倒数" —— 正好是 1/32 或 1/88。
`(x^y)&1 == 0` 选 1/32(此时非零抽头在 `dx+dy` 为奇的那一半),否则选 1/88。
这就是**在 Bayer 上做同色低通 / 把稀疏绿平面补成全平面**的标准做法。

**⚠️ 一个没解决的问题(未定)。**这里选出来的 `n` 是**整条 ymm 的标量广播**
(`vbroadcastss` 存进 `[rbp+0x20]` / `[rbp+0x40]`,`cmove` 只在两个地址之间选),
而 `r15d` 每次 +8,所以 `(x^y)&1` **在一行之内恒定**,只随 `y` 翻转。
可是一条 ymm 覆盖 8 个连续列,列奇偶是逐 lane 交替的 —— 严格说来每行只有一半的 lane
拿到了正确的归一化系数。三种可能:(a) 输出只在一个相位上被下游消费,另一半会被覆盖;
(b) 输入平面在水平方向另有约定;(c) 就是个近似/瑕疵。**没有证据,不猜。**
> 对照组:0x3b2be0 在同样的场合用的是 `vmovups` 载入一个 **4 float 循环模式**
> `(1/32,1/16,1/32,1/16)`,那样才是逐 lane 正确的。两处写法不同,值得留意。

## 6. 调用

* `3b3c12 call 0x7ff619ba5630` → RVA **0x355630**,`__security_check_cookie`。
* 无虚表槽调用,无内存分配。

## 7. 一句话定性

**CFA 相位感知的 5×5 同色低通**:对一张只在棋盘半格上有值的稀疏平面做加权求和,
按 `(x+y)` 奇偶在 1/32 与 1/88 两个归一化系数间二选一 —— 就是 demosaic 里"把稀疏绿补成稠密绿"那一步的形状。
