# 0x3b0f00 —— 水平同色 [1,6,1]/8 低通（带 2 列边界拷贝）

指令 85 条。

## 1. 签名

栈帧：`mov [rsp+8], rbx` → `push rdi` → `sub rsp,0x10`，入口 rsp = R，当前 rsp = R-0x18。

| 参数 | 寄存器 | 用法 | 读到的字段 |
|---|---|---|---|
| p1 | rcx | **未使用** | — |
| p2 | rdx → rbx | float 平面描述符，**输出** | +4 高、+8 行距、+0x10 数据 |
| p3 | r8 → rdi | float 平面描述符，**输入** | +4 高、+8 行距、+0x10 数据 |
| p4 | r9 | ROI 矩形对象（与 3af8d0 的 p5 同类型） | +8 = x0、+0xc = y0、+0x10 = x1、+0x14 = y1；返回前 `[r9] = &vftable(0x466678)` |

没有 memset：未覆盖区域保持原样。

## 2. 循环结构

- 外层：`r10d = y0`，`while (r10d < y1)`，每次 +1。**无行余量**。
- 内层向量：`r8d = x0+2`，`while (r8d < x1-2)`，每次 **+8**；指针 rcx/rdx 每次 += 0x20。
- 内层每轮重新读 [r9+0x10] 求 x1（无法提升）。
- **首尾各有 2 列标量直拷**：
  - 向量循环前：`dst[y][x0] = src[y][x0]`、`dst[y][x0+1] = src[y][x0+1]`（`mov eax,…/mov …,eax`，按 32 位整数搬运，不做浮点）。
  - 向量循环后：再拷 2 个 float（此时指针停在 `x0+2+8N`，即最后两列附近）。
- 无标量尾循环，尾部由向量越写覆盖。

## 3. 抽头几何

单一输入 p3，同一行：

| 输入 | 行偏移 | 列偏移 | 位移 | 权重 |
|---|---|---|---|---|
| p3 | 0 | -2 | -8 | 1 |
| p3 | 0 | 0 | 0 | 6 |
| p3 | 0 | +2 | +8 | 1 |

## 4. 常量

| RVA | 值 | 载入方式 | 角色 |
|---|---|---|---|
| 0x4DEADC | **0.125f** | `vbroadcastss ymm3` (3b0f31) | 1/8 归一化 |
| 0x4DF118 | **6.0f** | `vbroadcastss ymm4` (3b0f3a) | 中心抽头权重 |
| 0x559440 | — | `[rip+0x1a852f]` | __security_cookie |

死存储验证：`[rsp]` 被写入 `0x3e000000`(0.125) 和 `0x40c00000`(6.0)。

## 5. 算式

```
for y in [y0, y1):
    dst[y][x0]   = src[y][x0]
    dst[y][x0+1] = src[y][x0+1]
    for x in [x0+2, x1-2) step 8:
        dst[y][x] = 0.125 * (6*src[y][x] + src[y][x-2] + src[y][x+2])
    dst[y][x_last]   = src[y][x_last]
    dst[y][x_last+1] = src[y][x_last+1]
```
即同色三点核 **[1, 6, 1] / 8**（隔一列采样，Bayer 同色低通）。

## 6. 调用

| 目标 RVA | 形式 | 说明 |
|---|---|---|
| 0x3a5630 | 直接 call | __security_check_cookie |

无虚表调用、无 memset。

## 7. 一句话定性

**水平同色低通（[1,6,1]/8）**，边界两列直通拷贝——典型的「先把每行同色序列平滑一次再算方向代价」的预处理。
