# 0x3b4230 —— 逐点 lerp(带权混合)(113 条)

> 绝对地址基址 **0x7ff619850000**。`call 0x7ff619ba5630` → RVA `0x355630`。

## 1. 签名

栈帧:`push rbx/r12/r13/r14/r15`(5×8=0x28)+ `sub rsp,0x20` = 0x48。
`[rsp+0x70]` ↔ 入口 `[rsp+0x28]` = **第 5 参数**;`[rsp+0x78]` ↔ 入口 `[rsp+0x30]` = **第 6 参数**。共 **6 个参数**。

| # | 寄存器/槽 | 用法 |
|---|---|---|
| 1 | rcx | **没被读过**(ecx 立刻被 `[rbx+0xc]` 覆盖)。疑似 `this`。 |
| 2 | rdx→r14 | float 平面描述符,**输出** |
| 3 | r8→r15 | float 平面描述符,输入 A(t=0 一侧) |
| 4 | r9→r13 | float 平面描述符,输入 B(t=1 一侧) |
| 5 | [rsp+0x28]→r12 | float 平面描述符,**混合权 t** |
| 6 | [rsp+0x30]→rbx | **ROI 对象**(`+8`=x0, `+0xc`=y0, `+0x10`=x1, `+0x14`=y1);退出写回 `+0` = vftable 0x466678 |

平面字段:`+0x10` 数据、`+4` 高、`+8` 行距(字节)。

## 2. 循环结构

两层,无标量尾巴。

* 外层 `ecx = y`:`[roi+0xc]` → `[roi+0x14]`,`inc`。
* 内层 `r8d = x`:`[roi+8]` → `[roi+0x10]`,**每次 +8**(一个 ymm),无余数处理。
* 每行重算 4 个行基址,进内层前折成"相对 `rax = &A[y][x]` 的差值",循环里只推进 `rdi` 与 `rax`(各 +0x20)。
* `vbroadcastss ymm4, 1.0` 被放在**内层循环之外、外层之内**(3b4320),每行重载一次。

## 3. 抽头几何

纯逐点,每个输入只有 (0,0)。

| 输入 | (行偏移, 列偏移) |
|---|---|
| 参数 3 (A) | (0, 0) |
| 参数 4 (B) | (0, 0) |
| 参数 5 (t) | (0, 0) |

## 4. 常量

| 指令 RVA | 目标 RVA / VA | 数值 | 角色 |
|---|---|---|---|
| 3b423e | 0x559440 | (栈 cookie) | `__security_cookie` |
| 3b4320 | **0x4DEBBC** / 0x1404debbc | **1.0** | `ymm4`,算 `1-t` |
| 3b4389 | 0x466678 | vftable | 退出写回 ROI 对象 |

`3b432c mov dword ptr [rsp], 0x3f800000` 是同一个 1.0 的死存储(标量副本),无语义。

## 5. 算式

```
for y in [y0, y1):
  for x in [x0, x1) step 8:
    t = p5[y][x..x+7]
    p2[y][x..x+7] = (1 - t) * p3[y][x..x+7] + t * p4[y][x..x+7]
```

指令顺序:`ymm3 = t`;`ymm0 = t * B`(`[rdi]` = &B[y][x]);`ymm1 = 1 - t`;`ymm2 = (1-t) * A`(`[rax]` = &A[y][x]);`ymm1 = ymm2 + ymm0`;存到 `[r10+rax]` = &out[y][x]。
t 没有被 clamp 到 [0,1],也没有判据 —— 完全信任参数 5 的取值范围。

> 与 0x3b2be0 连起来看很自然:0x3b2be0 产出的那张 `[0.5, 0.96)` 控制图,形状上正好可以当这里的 `t`(**未验证**,只是形状相符)。

## 6. 调用

* `3b439b call 0x7ff619ba5630` → RVA **0x355630**,`__security_check_cookie`。
* 无虚表槽调用。

## 7. 一句话定性

**逐点混合(lerp)**:用第 5 张图当逐像素权重,在两张图之间线性插值。没有邻域、没有判据、没有查表。
