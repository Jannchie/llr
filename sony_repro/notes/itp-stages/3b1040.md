# 0x3b1040 —— 垂直同色 [1,6,1]/8 低通（3b0f00 的垂直孪生）

指令 117 条。

## 1. 签名

栈帧：`push rsi/r13/r15`（3 个）→ `sub rsp,0x30`，当前 rsp = R-0x48。
（p1..p4 全在寄存器里，未从 home slot 取。）

| 参数 | 寄存器 | 用法 | 读到的字段 |
|---|---|---|---|
| p1 | rcx | **未使用** | — |
| p2 | rdx → r13 | float 平面描述符，**输出** | +4 高、+8 行距、+0x10 数据 |
| p3 | r8 → r15 | float 平面描述符，**输入** | +4 高、+8 行距、+0x10 数据 |
| p4 | r9 → rsi | ROI 矩形对象 | +8 = x0、+0xc = y0、+0x10 = x1、+0x14 = y1；返回前 `[rsi] = &vftable(0x466678)` |

`mov [rsp], r9` 之后 [rsp] 被两个死存储覆盖（见常量节）。

## 2. 循环结构

- 外层：`r8d = y0+2`，`while (r8d < y1-2)`，每次 +1。**行方向留 2 像素余量**。同时维护 `r12d = r8d+2`。
- 内层向量：`r11d = x0+2`，`while (r11d < x1-2)`，每次 **+8**。
- 内层每轮重新读 [rsi+0x10]（x1），退出后重新读 [rsi+8]（x0）；外层每轮重新读 [rsi+0x14]（y1）。
- **没有任何边界拷贝**（与 3b0f00 的显著差别）：前后各 2 行、左右各 2 列的目标像素完全不写。
- 无标量尾循环。

行指针：源平面 p3 取 `y-2`(rbx)、`y`(r10)、`y+2`(r9) 三行；目标 p2 取 `y`(rdx)。列起点统一 `r11 = 4*x0 + 8`（= 列 x0+2）。随后 r10、rdx 减去 rbx 变成差量寻址，rcx = rbx + 列偏移，rdi = r9 + 列偏移。

## 3. 抽头几何

单一输入 p3，同一列：

| 输入 | 行偏移 | 列偏移 | 位移 | 权重 |
|---|---|---|---|---|
| p3 | -2 | 0 | 行距×(-2) | 1 |
| p3 | 0 | 0 | 0 | 6 |
| p3 | +2 | 0 | 行距×(+2) | 1 |

## 4. 常量

| RVA | 值 | 载入方式 | 角色 |
|---|---|---|---|
| 0x4DEADC | **0.125f** | `vbroadcastss ymm3` (3b106f) | 1/8 归一化 |
| 0x4DF118 | **6.0f** | `vbroadcastss ymm4` (3b1078) | 中心抽头权重 |
| 0x559440 | — | `[rip+0x1a83ef]` | __security_cookie |

死存储验证：`[rsp]` 被写入 `0x3e000000`(0.125)、`0x40c00000`(6.0)。与 3b0f00 完全同一对常量地址。

## 5. 算式

```
for y in [y0+2, y1-2):
    for x in [x0+2, x1-2) step 8:
        dst[y][x] = 0.125 * (6*src[y][x] + src[y-2][x] + src[y+2][x])
```

## 6. 调用

| 目标 RVA | 形式 | 说明 |
|---|---|---|
| 0x3a5630 | 直接 call | __security_check_cookie |

## 7. 一句话定性

**垂直同色低通（[1,6,1]/8）**，与 0x3b0f00 逐条对偶；差别只在于行/列余量对调、且不做边界拷贝。
