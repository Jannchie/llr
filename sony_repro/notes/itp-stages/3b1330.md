# 0x3b1330 — 同色垂直 2 抽头中点插值（101 条指令）

## 1. 签名
`void f(p1 /*未用*/, PlaneF32* pDst, PlaneF32* pSrc, Roi* pRoi)` —— 4 个参数。

| 参数 | 寄存器 | 类型 | 用法 |
|---|---|---|---|
| 1 | rcx | ? | 全函数未读取，推测 `this` |
| 2 | rdx→r13 | float32 平面描述符 | `+4`(高) `+8`(行距) `+0x10`(数据)。**写入目标** |
| 3 | r8→r15 | float32 平面描述符 | `+4` `+8` `+0x10`。**读取源** |
| 4 | r9→rdi | ROI/任务对象 | `+8`=x0, `+0xc`=y0, `+0x10`=x1, `+0x14`=y1；返回前往 `+0` 写 vftable |

同样有 `data==NULL` / `row>=height` 的行指针保护。

## 2. 循环结构
- 外层：`r11d = y`，从 `Roi.y0 + 2` 到 `Roi.y1 - 2`（`y1` 每轮重载 `[rdi+0x14]` 再减 2），步进 1；同时 `r14d = y+1` 同步递增。
- 内层：`r8d = x`，从 `Roi.x0` 到 `Roi.x1`（`x1` 每轮重载 `[rdi+0x10]`），**步进 8**。**x 方向不收缩**。
- do-while，同样可能多写至多 7 像素，**无标量尾**。
- 与 0x3b11f0 正好互补：那边缩 x 不缩 y，这边缩 y 不缩 x。

## 3. 抽头几何
基址：`rcx = pSrc.row(y-1) + 4*x0`，随 x 每轮 +0x20；`rdx = pSrc.row(y+1) - pDst.row(y)`（差值形式）；写地址 `rax = pDst.row(y) + 4*x0` 同步前进。

| 输入 | 行偏移 | 列偏移 | 汇编位移 |
|---|---|---|---|
| pSrc | −1 | 0 | `[rcx]` |
| pSrc | +1 | 0 | `[rdx+rax]` |
| **写 pDst** | 0 | 0 | `[rax]` |

## 4. 常量
| RVA | VA | 数值 | 角色 |
|---|---|---|---|
| 0x4DEB28 | 0x1404DEB28 | **0.5** | `vbroadcastss ymm3`，两抽头求平均（与 0x3b11f0 同一个常量地址） |
| 0x559440 | — | `__security_cookie` | 栈保护 |
| 0x466678 | 0x140466678 | vftable（同 0x3b11f0） | 退出前写进参数 4 的 `+0` |

死存 `mov dword ptr [rsp], 0x3f800000`… 实为 `0x3f000000` = 0.5f，印证广播值。

## 5. 算式
```
for y in [y0+2, y1-2):
  for x in [x0, x1) step 8:
    dst[y][x] = 0.5 * (src[y-1][x] + src[y+1][x])
```

## 6. 调用
- `call 0x7ff619ba5630` → RVA **0x3a5630** = `__security_check_cookie`。
- 无虚表调用。

## 7. 一句话定性
**纯逐点的同色垂直中点插值**；与 0x3b11f0 构成 H/V 一对，典型用于方向性去马赛克里先生成两条方向候选。
