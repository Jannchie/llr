# 0x3b2be0 —— 四方向活动度 → 各向异性控制图(811 条)【核对稿】

> 本篇是对 `notes/static-itp-spica.md` §2.7 的**独立复核**,不是新解。
> 绝对地址基址 **0x7ff619850000**(`call 0x7ff619ba5630` → RVA `0x355630`)。
> 末尾单列「与 §2.7 的出入」。

## 1. 签名

`mov rax, rsp` 开头,`push rbp/rsi/rdi/r12/r13/r14/r15`(7×8=0x38)+ `sub rsp,0x2f0`,共 0x328;
另存 xmm6..xmm15。`lea rbp,[rsp+0x40]; and rbp,~0x1f` 做对齐帧指针。
`[rsp+0x350]` ↔ 入口 `[rsp+0x28]` = **第 5 参数**(0x350−0x38−0x2f0 = 0x28)。共 **5 个参数**。

| # | 寄存器/槽 | 用法 |
|---|---|---|
| 1 | rcx | **没被读过**。疑似 `this`。 |
| 2 | rdx → `[rbp+0x88]` | float 平面描述符,**输出控制图**。读 `+0x10`、`+4`、`+8` |
| 3 | r8 → r13、`[rbp+0x60]` | float 平面描述符,**输入(马赛克)**。读 `+0`(宽)、`+4`(高)、`+8`(行距)、`+0x10`(数据) |
| 4 | r9 → rsi、`[rbp+0x98]` | **ROI 对象**:`+8`=x0、`+0xc`=y0、`+0x10`=x1、`+0x14`=y1;退出写回 `+0` = vftable 0x466678 |
| 5 | `[rsp+0x350]` → `[rbp+0x38]` | **调参块指针**,`#pragma pack(1)` 的 `{u8 flag; float p[11];}`;读 `+0x11/0x15/0x19/0x1d/0x21/0x25` = `p[4..9]` |

四张中间图的尺寸取自**参数 3** 的 `+0`(宽)与 `+4`(高),不是 ROI。

## 2. 循环结构

**两个独立的双层循环**,中间隔着一段常量准备。无标量尾巴。

**循环一(四张活动度图)**
* 行:`edx = y`,从 `y0+2`,条件 `y < y1-4`。
* 列:`r10d = x`,从 `x0+2`,条件 `x < x1-4`,步长 **8**。
* 用到输入的 5 行:y、y+1、y+2、y+4(和 y 本身)。

**循环二(聚合 → 取比 → 映射)**
* 行:`edx = y`,从 `y0+4`,条件 `y < y1-4`。
* 列:从 `x0+4`,条件 `x < x1-4`,步长 **8**。
* 每行重算 4×3~5 条行基址;进内层前折成相对主游标 `rsi` 的差值。

前后各分配 / 释放四张 w×h float 图(见 §6)。

## 3. 抽头几何

### 循环一 —— 三点共线活动度

主游标:`rcx = &in[y][x+4]`(k=0 时 `= row(y) + x0*4 + 0x18`,x = x0+2)。
`[rcx-0x10]` = 列 x、`[rcx-8]` = 列 x+2、`[rcx]` = 列 x+4。

| 图 | 存到 | 三个抽头(相对**存放位置**) | 方向 |
|---|---|---|---|
| buf0 | `[y][x]` | (0,0) (0,+2) (0,+4) | 水平,间距 2 |
| buf1 | `[y][x]` | (0,0) (+2,0) (+4,0) | 垂直,间距 2 |
| buf2 | `[y][x+2]` | (0,0) (+1,−1) (+2,−2) | 反对角,间距 1 |
| buf3 | `[y][x]` | (0,0) (+1,+1) (+2,+2) | 主对角,间距 1 |

四个方向各 3 次 `vandnps`(共 **12 次**,文件里 grep 得 12,吻合)。

### 循环二 —— 聚合核

设 `X = x0+2`(主游标 `rsi = &buf0[y-2][X]`),输出列 `x = X+2`。

| 图 | 窗口(行 × 列,列以 X 为准) | 核 |
|---|---|---|
| buf0 | y−2..y+2 × X−1..X+1 | `1 1 1 / 2 8 2 / 6 6 6 / 2 8 2 / 1 1 1`,和 **48** |
| buf1 | y−3..y−1 × X..X+4 | `1 2 6 2 1 / 1 8 6 8 1 / 1 2 6 2 1`,和 **48**(= buf0 的**转置**) |
| buf2 | y−2..y × X..X+2 | `1 1 1 / 1 4 1 / 1 1 1`,和 **12** |
| buf3 | y−2..y × X+2..X+4 | `1 1 1 / 1 4 1 / 1 1 1`,和 **12** |
| 输出 | `[r8+rsi+8]` = `out[y][X+2]` | |

**几何中心核对**(每张图自己带一个相位偏移,聚合窗口的位置就是在补这个偏移):
`buf0[y][c]` 的重心是 `(y, c+2)` → 窗口中心格 `(y, X)` → 重心 `(y, X+2)` = **(y, x)** ✓
`buf1[y][c]` 的重心是 `(y+2, c)` → 窗口中心格 `(y-2, X+2)` → 重心 **(y, x)** ✓
`buf2[y][c]` 的重心是 `(y+1, c-1)` → 窗口中心格 `(y-1, X+1)` → 重心 `(y, X)` = **(y, x−2)**
`buf3[y][c]` 的重心是 `(y+1, c+1)` → 窗口中心格 `(y-1, X+3)` → 重心 `(y, X+4)` = **(y, x+2)**
→ 轴向两张精确对准输出像素,**两条对角各偏 ∓2 列**(彼此关于输出像素对称)。这一点 §2.7 没提。

## 5. 算式

```
# ---- 循环一 ----
act(a,b,c) = |a + c - 2b| + |b - c| + |a - b|          # 12 次 vandnps
buf0[y][x]   = act(in[y][x],   in[y][x+2], in[y][x+4])
buf1[y][x]   = act(in[y][x],   in[y+2][x], in[y+4][x])
buf2[y][x+2] = act(in[y][x+2], in[y+1][x+1], in[y+2][x])
buf3[y][x]   = act(in[y][x],   in[y+1][x+1], in[y+2][x+2])

# ---- 循环二 ----
n_ax = (y 偶) ? (1/32,1/16,…) : (1/16,1/32,…)          # 4 float 循环模式,逐 lane
n_di = (y 偶) ? 0.25 : 0.125                            # 标量广播

A_h  = max(Sum48(buf0) * n_ax - p4, p5)
A_v  = max(Sum48(buf1) * n_ax - p4, p5)
A_d1 = max(Sum12(buf2) * n_di - p4, p5)
A_d2 = max(Sum12(buf3) * n_di - p4, p5)

r    = (A_h + A_v + 0.01) / (A_d1 + A_d2 + 0.01)
out  = max( min( (p7 - (r - p8)) * p9, p7 ), p6 )       # vminps 先、vmaxps 后
```

代入实测参数(p4=0, p5=1.0, p6=0.5, p7=1.0, p8=0.2, p9=0.8):

```
out = clamp( (1.2 - r) * 0.8, 0.5, 1.0 )
```

* 上钳 1.0 需要 `r ≤ −0.05`,`r` 恒正 → 够不到;实际值域 `[0.5, 0.96)`。
* `r ≥ 0.575` → 压到 0.5;平坦区四项都被 `max(·,1.0)` 顶到 1,`r = 2.01/2.01 = 1` → `clamp(0.16) = 0.5`。

## 7. 一句话定性

**判据/控制图生成**:四个方向的三点活动度 → 相位归一化聚合 → 轴向和 ÷ 对角和 → 仿射 + 双钳位。
输出的不是图像,是一张 `[0.5, 0.96)` 的**各向异性(对角优势)控制图**。

## 与 §2.7 的出入

逐条核对下来,§2.7 的**主干结论全部成立**:5 个参数、调参块是第 5 参数且偏移 `4k+1`、
`p[4..9] = 0/1.0/0.5/1.0/0.2/0.8`、`act` 的三项形式、四个方向的抽头几何、
`-0.0`/6.0/8.0/4.0/0.01 与四个归一化常量的 VA 与数值、`out = clamp((1.2−r)·0.8, 0.5, 1.0)`、
值域 `[0.5, 0.96)`、`r ≥ 0.575` 压到下钳、平坦区 `r = 1` → 0.5、"这不是色度降噪"这条更正 —— 都对。
12 次 `vandnps` 与 811 条指令也对得上。

有出入 / 需要补正的地方:

1. **buf1 的聚合核是 buf0 的转置,不是同一个矩阵。**
   §2.7 写「轴向(buf0 / buf1),5×3」并只给了一个 5 行 3 列的矩阵。
   实际 buf0 是 5 行 × 3 列(`1 1 1 / 2 8 2 / 6 6 6 / 2 8 2 / 1 1 1`),
   buf1 是 **3 行 × 5 列**(`1 2 6 2 1 / 1 8 6 8 1 / 1 2 6 2 1`)。两者和都是 48,是严格的转置关系,
   但"同一个核"这个说法会误导复刻。相应地,§2.7 常量表里把 8.0 记成「轴向核的中心列」、
   6.0 记成「轴向核的中间行」,这两句只对 buf0 成立,对 buf1 要行列互换。

2. **「两边配成对(48/16 = 12/4 = 3、48/32 = 12/8 = 1.5)」只在一半的列上成立。**
   轴向归一化 `ymm11` 是一个**逐 lane 交替**的 4 float 模式(同时看行、列奇偶),
   而对角归一化 `ymm12` 是**整条 ymm 的标量广播,只看行奇偶**。
   于是在同一行里,列奇偶变化时轴向系数在 1/16↔1/32 之间翻,对角系数纹丝不动 —— 
   `48·n_ax` 与 `12·n_di` 只有一半的列真的配成 3↔3 或 1.5↔1.5,另一半是 1.5↔3 或 3↔1.5。
   §2.7 自己在上两行已经正确写出了两者的依赖差异,但接着的"配成对 / 比值无量纲"这句
   与之矛盾。**结论:比值 r 在列方向上有一个 2× 的锯齿,不是无量纲的。**(这是我读到的最实质的一条。)

3. **四个聚合窗口没有对齐到同一个像素。**§2.7 完全没讨论这件事。
   实测:buf0、buf1 的窗口重心精确落在输出像素 `(y,x)` 上,
   但 buf2 的重心在 `(y, x−2)`、buf3 的重心在 `(y, x+2)`。
   两条对角的代价是从输出像素左右各 2 列处取的(彼此对称,所以整体仍对两条对角对称,
   §2.7"对两条对角对称"的结论不受影响),但复刻时若按"同一像素上的四个方向代价"写就会有 2 像素错位。

4. **循环边界比「在 ROI 内逐像素」更紧,而且两个循环不同。**
   循环一:`y ∈ [y0+2, y1-4)`、`x ∈ [x0+2, x1-4)`;循环二:`y ∈ [y0+4, y1-4)`、`x ∈ [x0+4, x1-4)`。
   列步长恒为 8 且**没有标量余数处理**,所以右边界会按整块 ymm 写出去,最多越过 `x1-4` 七个像素。
   §2.7 的「四周 16 像素 halo」是运行时实测的 ROI,和这里的静态内缩是两回事,两条都对但别混用。

5. **四张中间图的尺寸来自第 3 参数(输入平面)的 `+0` / `+4`,不是 ROI。**§2.7 只说「w×h」,没指明来源。

6. **小措辞。**§2.7 说对角抽头「间距 1,在 Bayer 上落在绿格」。
   间距 (1,1) 保持 `x+y` 的奇偶,所以三个抽头**与锚点同色**;只有当锚点本身是绿格时才"落在绿格"。
   对 R/B 锚点,三个抽头都是 R/B。

7. **(不算出入,记一笔)**反汇编文本里的绝对地址用的基址是 **0x7ff619850000**,
   不是任务说明里的 0x7ff619800000;`call 0x7ff619c02be0` 减 0x7ff619850000 才等于 `0x3b2be0`。
   rip 相对位移用「下一行的 RVA + 位移」算出来的目标(0x4df118 等)与 §2.7 的 VA 表一致,说明列首那一列确实是 RVA。
