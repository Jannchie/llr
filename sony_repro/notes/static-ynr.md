# ZcTaskYNR:中值滤波 + Sobel 二值掩码 + 百分比混合

全部静态读出,没有用动态 hook。四个函数读完即闭合,没有留下未解的分支。

| 角色 | 地址 | 说明 |
|---|---|---|
| `ZcTaskYNR::execute` | `0x14039d230` | 分发器,不含算法 |
| 混合核心 | `0x14039d5a0` | 逐像素 `blend(A, B, C)` |
| 掩码构建 | `0x14039d740` | Sobel + 硬阈值 |
| 3×3 中值 | `0x1401ce7f0` | 收集 9 个 tap → 排序 → 取第 5 个 |
| 5×5 中值 | `0x1401ce980` | 收集 25 个 tap → 排序 → 取第 13 个 |
| 排序 | `0x1401ceaf0` | MSVC STL introsort(`0x1401cedd0` 是三点取中划分) |

vftable 槽位 `+0x38` 就是 execute —— `tools/task_execs.json` 里记的 `rva` 正是这个槽,
六个 NR task 的表布局完全一致,不需要 Ghidra 就能定位。

## 1. 算法

```
T    = cfg[+0x234]          # Sobel 阈值
P    = cfg[+0x22c]          # 混合百分比, 0..100
mode = cfg[+0x230]          # == 2 → 5×5 中值; 否则 3×3

B = median(A, 5 if mode == 2 else 3)

# A 上的标准 Sobel
gy = (A[y+1][x-1] + 2*A[y+1][x] + A[y+1][x+1])
   - (A[y-1][x-1] + 2*A[y-1][x] + A[y-1][x+1])
gx = (A[y-1][x+1] + 2*A[y][x+1] + A[y+1][x+1])
   - (A[y-1][x-1] + 2*A[y][x-1] + A[y+1][x-1])
C  = ((gx*gx + gy*gy) / 2 > T*T) ? 0xffff : 0

w   = ((0xffff - C) * P) / 100
out = (A * (0xffff - w) + B * w) / 0xffff
```

归一化后就是一句话:**边缘处原样输出,平坦处按 `P/100` 混向中值。**

### 反汇编里认这三个除法

* `0x51eb851f` + `sar 5` + 加符号位 = **除以 100**
* `0x80008001` + `add edx, n` + `sar 15` + 加符号位 = **除以 65535**
* `cqo` + `sub rax, rdx` + `sar rax, 1` = **除以 2**(向零取整)

### 两个容易搞错的细节

1. 判据是 `(gx² + gy²) / 2 > T²`,即两个分量的**均方根**超过 T,不是模长
   `sqrt(gx²+gy²)`。差一个 `sqrt(2)`。
2. 掩码循环是**半开** ROI(`jl` / `jge`,`y < y1`),混合循环是**闭**区间
   (`jle` / `jg`,`y <= y1`)。两处不一致,复现时别统一。
   而且两处都不做边界钳制:掩码读 `y±1`/`x±1`,5×5 中值读 `±2`,
   调用方必须把 ROI 内缩,否则越界读。

平面访问一律是 `data = plane[+0x20]`,`stride = plane[+0x14]`,
元素 `u16 at [row + 2*x]`。

## 2. 参数从哪来

```
settings.vt[0x38](settings, 0x8027, 0)   →  params[+0x21c]
params[+0x21c]                           →  params[+0x22c]   (0x140169813)
```

即 **recipe 里的设置键 `0x8027` 直接就是百分比 P**,没有经过
`t = (UI-50)*2` 那套映射(那是 RawNR 三个滑块的存法,见 static-rawnr.md §7)。

同一个 reader(`0x140168cf0` 附近)按键读了一串:

| key | 落到 |
|---|---|
| `0x801d` | `+0x214` |
| `0x801e` | `+0x218`(16 位) |
| `0x8027` | `+0x21c` → P |
| `0x8028` | `+0x220` |
| `0x8029` | `+0x224` → `+0x228` |
| `0x8022` | `+0x238`(16 位) |

### 构造函数给的默认值(`0x14014e580`)

| 字段 | 默认 | 含义 |
|---|---|---|
| `+0x22c` | **0** | P —— **默认 YNR 完全不工作** |
| `+0x230` | 1 | mode → 3×3 中值 |
| `+0x234` | `0x1fff` = 8191 | Sobel 阈值 T |
| `+0x1ec` | `0x1770` = 6000 | |
| `+0x240` / `+0x244` | `0x32` = 50 | 两个滑块中性值 |
| `+0x248` | 1 | |
| `+0x25c` / `+0x264` | −1 | |

`+0x22c` 默认 0 这条很重要:**YNR 不是 Edit 的常开级**,只在降噪控件被动过
(即 `0x8027` 被写成正值)时才真正改变像素。所以它解释不了「机内直出 JPG 比
llr 导出干净」—— 直出的干净来自机身管线,不是 Edit。

另有 `0x14015ae43` 把 `+0x21c` / `+0x224` 初始化成 −100 / −80,看着是「未设置」
哨兵而不是可用值(P 为负会让 w 为负)。

## 2.5 实测(`tools/ynr_ref.py`)

σ = 30 的平坦噪声场 + 一个孤立脉冲,默认 T = 8191、3x3:

| P | 噪声 std | × | 孤立脉冲残留 |
|---|---|---|---|
| 0(中性 UI 50) | 30.0 | 1.00 | 100% |
| 50 | 17.9 | 0.60 | 50% |
| 100 | 12.4 | **0.41** | **0.0%** |
| 100, 5x5 | 7.6 | 0.25 | — |
| −100 | 57.9 | 1.93 | — (锐化方向) |

脉冲残留恰好等于 `1 - P/100`,因为中值把它清成背景、混合再按 `P/100` 取回 ——
**P = 100 时彻底清零**。这正是 BSNR_Y 做不到的事(见 static-bsnr-y.md §4:
残留 28.4%)。

### T = 8191 的掩码几乎从不命中

一个 500 → 3000 的阶跃(Δ = 2500)**都不触发**。判据 `(gx²+gy²)/2 > T²`
对幅度 Δ 的干净阶跃给出 `gx = 4Δ`,于是命中条件是

```
16Δ² / 2 > T²   →   Δ > T / sqrt(8) = 8191 / 2.828 ≈ 2896
```

即只有超过约 **17.7% 满刻度**的边才被保护,其余一律中值化。
自检里阶跃两侧电平仍然保住 —— 那是**中值自身的性质**,不靠掩码。
掩码存在是为了保护单像素细线那类中值会毁掉的细节。

## 3. 对 llr 的意义

llr 现在的 `WaveletDenoiser` 用 garrote 收缩,它的 docstring 自己承认:

> garrote shrinkage — which is built to keep large coefficients — preserves them
> perfectly

孤立脉冲(热点、死点、彩色斑点)正是「大系数」,所以现行算法**在结构上**保不住
这些点:它把周围颗粒清干净,却让斑点从颗粒里的隐形变成干净背景上的显眼杂点
(`denoise.py` 的 `_clamp_impulses` 就是为补这个洞加的,量到过 0.005% → 0.52%)。
中值滤波是杀脉冲的正解,而 Edit 用的就是中值。

**待解的复现障碍:T 的域。** T = 8191 是在 Sony 的 **Y 域**(过完 tone + YGamma
LUT,见 static-chromasuppres.md §1)的 16 位刻度上标定的,不是场景线性域。
llr 的 worker 输出的是场景线性,直接搬 8191 会错得很远。忠实的落点应该是
**tone 曲线之后**,也就是 Sharpness / Spica 已经在的那一级(WebGL 管线),
而不是 worker 的马赛克域。

## 4. 邻居

`ZcTaskBSNR_Y`(`0x14039d050`)**已解出,见 `static-bsnr-y.md`** —— 它才是常开的
那一级,而 YNR 在中性档位是恒等变换。两者由同一个字段 `params[+0x21c]` 驱动:

| t = `params[+0x21c]` | UI | BSNR_Y | YNR |
|---|---|---|---|
| −100 | 0 | 关 | `P<0`,朝远离中值外插(锐化) |
| 0 | 50 | 全开 | `P=0`,**恒等** |
| +100 | 100 | 全开 | 混向中值 100% |

仍未读:`ZcTaskSIMDBSNR_Y`(`0x14039bf40`)、`ZcTaskRawNrPBX`(`0x1403b4bb0`),
以及 BSNR_Y 的高通平面构建 `0x14039c960`。
