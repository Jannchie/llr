# ZcTaskSharpness(标量孪生版)静态反编译

* 反编译产物:`tools/sharpness_decomp.c`
* 标量版 `ZcTaskSharpness` exec RVA **`0x388c00`**(2548 字节),SIMD 版
  `ZcTaskSIMDSharpness` RVA **`0x386da0`**(7651 字节)。
* **两版参数读取逐句相同**(已对照 `0x386da0` 前 60 行),标量版可直接当规范用。

## 0. 参数块的两个来源(先厘清,后面全靠它)

exec 签名是 `f(this, ZcTask* task, void** a)`:

| 记号 | 取法 | 是什么 |
|---|---|---|
| `st` | `a[1]` | **渲染设置块**,由 `FUN_140168b60`(RVA `0x168b60`)从 Imaging Edge 的编辑参数表灌入,字段 id 是 `0x80xx`/`0x90xx` |
| `arw` | `a[0]`,`dynamic_cast<ZcARW*>` | `sony_zhacai::ZcARW` |
| `calib` | `arw->vt[0xd8](arw, st[0x1e0])` | **逐图标定块** |

> **`calib` 与 PIPELINE.md §4 的 `lv` 是同一块内存。** ChromaSuppres(`0x36e920`)
> 同时用两条路取它:`arw->vt[0xd8](st[0x1e0])` 和 `*(*(task+0x68)+0xc8)`,
> 分别读 `+0xf00` 与 `+0x118f6`;而 `+0xf00` 和 `+0x118f6` 都由同一个解析器
> `FUN_14015f540` 写进同一个 `param_3`。所以 §4 的 `lv` 就是这里的 `calib`,
> 「tone LUT 在 lv+0x118f6」和「SSCS 阈值在 +0xf82」说的是一块东西。
> `arw->vt[0xd8]`(`FUN_140157630`)只是按 `record->[0x20] == id` 在
> `arw+0x68` 的数组里挑一份,挑不到就回落 `arw+0xe0`。

## 1. 伪代码(逐行对应 `0x388c00`)

只动 **plane 0**(`FUN_140152710(task->planes, 0)`),`uint16`,**原地**改写。
plane 字段:`+8` 宽、`+0xc` 高、`+0x14` 行距(字节)、`+0x20` 数据。
有效矩形 `task+0x30..0x3c` = `(x0, y0, x1, y1)`。

```c
/* ---- 参数 ---- */
gp   = (st[0x20c] + 100) / 100.0f;      /* 正向(过冲侧)斜率 */
gn   = (st[0x210] + 100) / 100.0f;      /* 负向(欠冲侧)斜率 */
th   = st[0x214];
hi   = (th < 0) ? (th + 100) * 0.25f    /* th=-100 -> 0 */
                : (float)(th + 25);     /* th=0 两支都给 25,连续 */
lo   = -hi;                             /* 常量 DAT_1404df2cc = -1.0f */

S    = st[0x208];                       /* 锐化强度 */
r    = st[0x2c4];                       /* 细/粗平衡(见 §3) */
raw  = r / 50.0f;
K    = calib[0x1060];                   /* 机型/标定系数,float,见 §4 */

gain = (S + 100) * 0.5f * K * raw / 25.0f;      /*  == (S+100)*K*r/2500  */

t    = (raw <= 1.0f) ? (raw - 1.0f) * 0.75f + 0.25f
                     :  raw * 0.25f;            /* 两个模糊核的混合权重 */

/* iso/机型 taper:默认 1.0 */
f    = arw[0x2275c];                    /* 默认 1.0f;RAW tag 0x703a[1]==5 时 1.5f */
if (f == 1.0f) taper = 1.0f;
else if (arw[0x1ac] < S) {              /* arw[0x1ac] 默认 0 */
    u     = (100 - S) / (100 - arw[0x1ac]);
    taper = 2.0f * (1.0f - u) + f * u;  /* S->100 时趋近 2.0 */
} else taper = f;

/* ---- 两张模糊图 ---- */
/* A:3x3 十字低通,和为 8 */
fine[y][x] = ( src[y][x-1] + 4*src[y][x] + src[y][x+1]
             + src[y-1][x] + src[y+1][x] ) * 0.125f;

/* B:7x7 可分离二项式核 [1,6,15,20,15,6,1],每方向和 64,总和 4096 */
wide[y][x] = (K7 ⊗ K7 ⊗ src)[y][x] * (1.0f/4096.0f);

/* ---- 合成 ---- */
for (y = y0; y < y1; ++y) for (x = x0; x < x1; ++x) {
    float s  = src[y][x];
    float d  = s - ( fine[y][x] * (1.0f - t) + wide[y][x] * t );   /* 高频 */

    if      (d >  hi) d = d * gp;
    else if (d >= lo) d = 0.0f;          /* 死区,硬门限(不是软阈值!) */
    else              d = d * gn;

    float o = s + d * gain * taper;
    src[y][x] = (uint16)(o < 0 ? 0 : (o > 32767 ? 32767 : (int)o));  /* 截断 */
}
```

常量核对(全部实测自 PE):

| 符号 | 值 |
|---|---|
| `DAT_1404df118 / DAT_140468bec / DAT_1404df1d0` | 6 / 15 / 20 → 二项式核 |
| `DAT_1404deadc` | 0.125 = 1/8(十字核归一) |
| `DAT_140466950` | 0.000244141 = 1/4096(7x7 归一) |
| `DAT_1404deae4 / DAT_140468be8` | 0.25 / 0.75(t 的映射) |
| `_DAT_14046679c / DAT_1404df210 / DAT_140468bf0` | 50 / 100 / 25 |
| `DAT_1404deb28 / DAT_1404debbc / DAT_1404df2cc` | 0.5 / 1.0 / −1.0 |
| `DAT_1404667a0` | 32767.0(上钳) |

## 2. 参数从设置块哪来(`FUN_140168b60` 逐条对照)

| 偏移 | 编辑参数 id | 取值器槽 | 用途 |
|---|---|---|---|
| `st+0x1e0` | `0x8000` | `vt[0x18]` | 选 calib 记录的 id |
| `st+0x208` | **`0x801a`** | `vt[0x38]` | **锐化强度 S** |
| `st+0x20c` | `0x801b` | `vt[0x38]` | 正向斜率 |
| `st+0x210` | `0x801c` | `vt[0x38]` | 负向斜率 |
| `st+0x214` | `0x801d` | `vt[0x38]` | 阈值 |
| `st+0x2c4` | **`0x901d`** | `vt[0x18]` | 细/粗平衡 r |

⚠️ **`st+0x2c4` 只在版本号 `> 0x102` 时才写**(`FUN_140168b60` 末尾
`if (0x102 < iVar11)`)。若没写过而残留 0,则 `gain = 0` 且 `t = -0.5`,
**整个锐化不生效**。这条必须动态确认。

⚠️ **机内 Sharpness 档位怎么变成 `0x801a` 的,静态没解出。** `0x80xx` 是
Imaging Edge 自己的编辑参数编号(PIPELINE §7.8.5 已记),不对应任何 RAW 标签;
应用在别处把 MakerNotes 的 Sharpness 翻译成这个数。我没有找到那段翻译代码。
`(S+100)` 这个式子说明 S 的量纲是「百分比偏移」,S=-100 时增益归零 ——
和机内 −3..+5 的档位显然不是同一刻度。

## 3. `st+0x2c4` 是「细节 / 轮廓」平衡,不是单纯的半径

同一个 `st+0x2c4` 在 **`ZcTaskSpica`**(RVA `0x358be0`)里以 **互补形式**出现:

```
Sharpness :  权重 ∝  r / 50
Spica     :  权重 ∝ (100 - r) / 50        /* spica_decomp.c, 第二遍混合 */
```
而且两边都再乘 `(st[0x208] + 100)/100`(同一个强度 S)。
**所以 Sharpness(7x7 二项式尺度)和 Spica(边缘自适应细锐化)是同一把
锐化的粗端与细端,由 `0x2c4` 在两者之间分配。** 只实现 Sharpness 一端
在 r 偏小的图上会明显不足。

## 4. `calib[0x1060]` 的来源

`FUN_14015f540`(标定解析器)里:

```c
calib[0x104c] = tag 0x78cd;
calib[0x1050] = tag 0x78ce;
if (calib[0x104c] > 0x100) {
    calib[0x1060] = (calib[0x104c] - 0x100) * 0.003125f + 1.0f;   /* 0.003125 = 1/320 */
    if (calib[0x1048] > 0x100) calib[0x1048] = 0x100;
}
```

⚠️ `tag 0x78cd <= 256` 时 **`calib[0x1060]` 根本不被写**,保持初值。
初值是多少静态没确认(标定块由 `operator_new` + 部分清零构造)。
若为 0 则 `gain = 0`。**这一条也要动态读一次**(`arw->vt[0xd8]` 的返回值 `+0x1060`)。

## 5. 与降噪的耦合

**没有直接耦合。** Sharpness 不读任何 NR 参数,也不看 ISO。
唯一带一点「机型/拍摄条件」味道的是:

* `calib[0x1060]`(来自 RAW tag `0x78cd`,与 RawNR 的 `0x78c5..0x78cc` 同一批标签,
  所以间接与噪声标定同源);
* `arw[0x2275c]`(RAW tag `0x703a[1] == 5` 时 1.5),`0x703a` 是拍摄模式类字段。

## 6. 作用色彩空间

Sharpness 排在 `SIMDITP → SSCS → AreaCompSIMD` 之后、`SIMDSpica → SIMDMarble` 之前,
**只改 plane 0**。同段的 SSCS 把三个平面当 R/G/B 用(权重 32/64/32),
AreaComp 把 plane1/plane2 当 Cb/Cr 用 —— 这两条在 PIPELINE 里已记且互相矛盾,
我这边只能确认 **Sharpness 动的是 plane 0**,平面语义未定论。

## 7. 没解出的部分(明确标出)

1. 机内 Sharpness 档位 → 编辑参数 `0x801a` 的换算表。
2. `st+0x2c4`(`0x901d`)的实际取值范围与默认值。
3. `calib[0x1060]` 在 tag `0x78cd <= 256` 时的残留初值。
4. `st+0x20c/0x210/0x214` 三个子参数是否有 UI 暴露、默认是多少。
5. 边界处理:缓冲区带 3 像素围边(`FUN_1401869f0` 分配 `w+6 × h+6`,
   行内偏移 `+0xc`),但围边**从不被填充**(memset 0),所以贴边 3 像素
   的模糊值偏低。这是引擎的行为,不是我读错;复刻时要照抄还是补边,取决于
   tile 之间是否有 28 像素外扩(`task+0x18..0x24` 说有),多半被外扩吃掉了。
